# GC-AutoCapture

Change history / ประวัติการเปลี่ยนแปลง: [CHANGELOG.md](CHANGELOG.md)

สคริปต์ Adobe Illustrator สำหรับส่งออก JPG ตามขอบเขต Rectangle ที่มี `height > 10` pt ใน Layer หรือ Group ตามรายชื่อ `CONFIG.frameLayerNames` รองรับ EPS ที่เปิดอยู่และการประมวลผล EPS หลายไฟล์แบบ batch

## ScriptUI สำหรับ EPS และ Batch

1. เลือก **File > Scripts > Other Script…** ใน Illustrator แล้วเปิด `GC-AutoCaputre.js`
2. เลือก **EPS ที่เปิดอยู่ปัจจุบัน** เพื่อส่งออกเอกสาร EPS ที่ active หรือเลือก **Batch** เพื่อประมวลผลหลายไฟล์
3. สำหรับ Batch กด **Browse...** ในส่วน **EPS files** แล้วเลือก Folder ต้นทาง สคริปต์จะค้นไฟล์นามสกุล `.eps` ใต้ Folder และ Subfolder ทั้งหมด และเรียงตาม path ก่อนทำงาน
4. ทุกโหมดต้องเลือก **Folder ปลายทาง (Output และ Log)** ที่มีอยู่จริงก่อนกด **เริ่มส่งออก** ช่องนี้ใช้เก็บทั้ง JPG, log ราย Job และ log สรุปรอบ
5. ใน Batch สคริปต์เปิด EPS ทีละไฟล์ ส่งออกและคืนสถานะ แล้วปิดไฟล์ที่สคริปต์เปิดเองโดยไม่บันทึกก่อนทำไฟล์ถัดไป หากไฟล์นั้นเปิดอยู่แล้วจะใช้เอกสารเดิมและไม่ปิดให้
6. เมื่อจบรอบ จะแสดงจำนวน Job, JPG, รายการที่ข้าม และตำแหน่ง `AutoCapture_Batch_*.txt`

สคริปต์สร้าง Batch log ทันทีหลังยืนยัน Destination และก่อนตรวจข้อมูลหรือเปิด EPS จึงบันทึกข้อผิดพลาดจากการค้นไฟล์ การเปิด EPS การตรวจข้อมูล การส่งออก การคืนสถานะ และการปิดเอกสารก่อนแสดง Error Alert หากยังไม่ได้เลือก Destination หรือเลือก path ไม่ถูกต้อง ScriptUI จะแสดงข้อความในหน้าต่างแทน Alert เพราะยังไม่มีตำแหน่งที่เขียน log ได้

Batch จะทำไฟล์ถัดไปต่อเมื่อ Job หนึ่งผิดพลาด และสรุปข้อผิดพลาดทั้งหมดเมื่อจบรอบ หากไม่พบ EPS ใต้ Folder ที่เลือกจะบันทึกเหตุผลใน Batch log แล้วแสดง Error Alert ส่งต่อ `GC-AutoCaputre.js` ไฟล์เดียวได้ และควรใช้ Folder ปลายทางแยกเมื่อทดสอบเพราะ JPG ชื่อเดิมอาจถูกเขียนทับ

## เริ่มใช้งานผ่าน Illustrator (เอกสารที่เปิดอยู่)

1. เปิดเอกสาร EPS ใน Illustrator และเตรียม Layer หรือ Group ชื่อตรงกับ `CONFIG.frameLayerNames`: `CutLine`, `Cut-Line`, `กรอบ`, `Layout` หรือ `FrameLine` โดยไม่แยกตัวพิมพ์เล็ก–ใหญ่และตัดช่องว่างหัวท้ายก่อนเทียบ
2. วาง Rectangle ที่มี `height > 10` pt ไว้ภายใน container นี้ รวม Group ซ้อนหรือ sublayer ได้
3. ตั้งชื่อเอกสารตาม job เช่น `1028(M)-TT-N012-03-01.eps` และเตรียม Group ชิ้นงานใน Layer `Name` พร้อม TextFrame ใน Layer `OID` ตามรายละเอียดด้านล่าง
4. เลือก **File > Scripts > Other Script…** แล้วเปิด `GC-AutoCaputre.js`
5. เลือก **EPS ที่เปิดอยู่ปัจจุบัน**, เลือก Folder ปลายทาง แล้วกด **เริ่มส่งออก** จะได้ไฟล์ เช่น `N012-03-01-12345678901234567890-003.jpg` พร้อม log ราย Job และ log สรุปรอบ

ชื่อไฟล์ปัจจุบันสะกดว่า **GC-AutoCaputre.js** ตามไฟล์ในโปรเจกต์ โปรดใช้ชื่อนี้ในการติดตั้งและทดสอบ

ปัจจุบันใช้ไฟล์นามสกุล **`.js`** สำหรับพัฒนาและส่งมอบ สามารถเลือกไฟล์นี้ผ่านเมนูข้างต้นได้โดยใช้ชื่อเดิม สคริปต์ยังทำงานด้วย Adobe Illustrator ExtendScript และใช้ไวยากรณ์ JavaScript แบบ ES3

## ชื่อไฟล์และการจับคู่ Order ID

รูปแบบส่งออกคือ `[SKU]-[รหัสรูปแบบ]-[ลำดับที่]-[Order ID]-ลำดับตำแหน่ง.jpg`

- **SKU, รหัสรูปแบบ และลำดับที่**: ชื่อเอกสารต้องลงท้ายด้วย `[SKU]-[รหัสรูปแบบ]-[ลำดับที่]` โดย SKU มี 4 ตัว รหัสรูปแบบมี 1–3 ตัว ทั้งสองส่วนใช้ตัวอักษรอังกฤษและ/หรือตัวเลข ส่วนลำดับที่ต้องเป็นตัวเลข 2 หลัก เช่น `N012-11-01.eps`, `L007-C-01.eps` และ `1102(M)-SP-L007-N02-01.eps` ชื่อสุดท้ายแยกเป็น `SKU=L007`, `Format=N02`, `Sequence=01` โดยไม่บังคับหรือตรวจเดือน/วันและ prefix ที่อยู่ก่อน SKU
- **ลำดับตำแหน่ง**: ใช้ลำดับกรอบหลังเรียงจากซ้ายไปขวา โดยกรอบซ้ายสุดเป็น 1 และเติมศูนย์ตาม `fileNumberDigits` เช่น `001`, `002`, `003` ไม่อ่านเลขชิ้นงานจาก Layer `Name` อีกต่อไป หากกรอบหนึ่งถูกข้าม กรอบถัดไปยังคงเลขตามตำแหน่งเดิม และเลขตั้งแต่ 1000 ขึ้นไปไม่ถูกตัด
- **Order ID**: ค้นวัตถุ Type ภายใน Layer `OID` รวม Group ซ้อนกัน แล้วใช้จุดกึ่งกลาง `geometricBounds` ตรวจว่า OID อยู่ในกรอบส่งออกใด ไม่ใช้ลำดับซ้อนใน Layers panel อ่านค่าจาก **Name ของวัตถุ** ก่อน หาก Name ว่างจะอ่าน `contents` รองรับเลขล้วนหรืออักษรอังกฤษผสมตัวเลข เช่น `123456`, `ABC123` และ `123ABC` โดยเก็บเป็นข้อความเพื่อรักษาศูนย์นำหน้าและเลขออเดอร์ยาว ขอบร่วมเป็นของกรอบทางขวาหรือด้านล่าง
- **จำนวนชิ้นงาน**: ใช้ Group ชั้นนอกใน Layer `Name` เป็นตัวแทนชิ้นงานจริง 1 Group = 1 ชิ้น รวม Group ที่อยู่ใน sublayer แต่ไม่นับ Group ย่อยภายในชิ้นงานซ้ำ ใช้จุดกึ่งกลาง `geometricBounds` ของ Group ระบุกรอบ โดยไม่อ่านชื่อหรือเลข `N...` กรอบที่ไม่มี Group จะถูกข้ามแม้มี OID อยู่
- **การจับคู่**: แต่ละกรอบต้องพบ Group ชิ้นงานหนึ่งรายการและควรมี TextFrame ของ OID หนึ่งรายการในพื้นที่เดียวกัน หาก OID ขาดหรือว่างจะใช้ `EmptyOID` โดยไม่เลื่อน OID จากกรอบอื่นมาแทน เลขท้ายชื่อ JPG มาจากตำแหน่งกรอบโดยตรง เช่น กรอบที่ 3 ใช้ `003` แม้กรอบที่ 2 ถูกข้าม
- **วันเวลา**: บันทึกใน log แทนชื่อ JPG ใช้เวลาท้องถิ่นของเครื่อง โดยอ่านเวลาที่ส่งออกแต่ละภาพเสร็จใหม่หลัง `exportFile` สำเร็จ

เมื่อกรอบมี Group ชิ้นงานหนึ่งรายการ แต่ไม่มี Layer `OID` ไม่มี TextFrame ของ OID หรือค่า OID ว่าง/ไม่ถูกต้อง สคริปต์จะยังส่งออกด้วย `EmptyOID` เช่น `N012-11-01-EmptyOID-002.jpg` ตัวอย่าง Name มี 4 Group และ OID มี 3 TextFrame ที่จับคู่ได้ จะส่งออก 4 ภาพ โดยตำแหน่งที่ขาดใช้ `EmptyOID` หากไม่มี Layer `Name` ไม่มี Group ในกรอบ พบ Group หลายรายการหรือ OID หลายรายการในกรอบเดียว หรือ Group/OID อยู่ในหลายกรอบที่ซ้อนกัน จะข้ามกรอบพร้อมเหตุผลใน log หากข้ามทั้งหมดจะยังเก็บ log ที่ปลายทางโดยไม่แก้ Artboard หรือ visibility เมื่อจบคิวจะแสดงจำนวนภาพที่ส่งออกและข้ามพร้อมตำแหน่ง log

ใช้ชื่อ Layer `Name` และ `OID` ตรงตามตัวพิมพ์ โดยค้น sublayer ได้และใช้ Layer แรกที่พบ สามารถเก็บ TextFrame ของ OID ใน Group ซ้อนกันได้ แต่ต้องวางจุดกึ่งกลางของ Group ชิ้นงานและ OID ภายในกรอบที่ต้องการจับคู่ จำนวน Group ใช้ยืนยันชิ้นงาน ไม่ใช่การตรวจว่า JPG ที่ render จะมีภาพเสมอไป และ Group ที่อยู่นอกกรอบจะไม่สร้างพื้นที่ส่งออกใหม่

## บันทึกการส่งออก

หลังคลิก **เริ่มส่งออก** แต่ละ Job ที่ผ่านการตรวจ Layer กรอบและชื่อเอกสารจะสร้างไฟล์ UTF-8 ชื่อ `AutoCapture_Log_yyyymmdd_HHMMSS.txt` ในโฟลเดอร์เดียวกับ JPG โดยเวลาในชื่อ log คือเวลาเริ่ม Job นั้น หากชื่อซ้ำภายในวินาทีเดียวจะเติม `_02`, `_03` เพื่อเก็บประวัติเดิม การเลือกปลายทางอย่างเดียวยังไม่สร้าง log

- `START`: ชื่อ/พาธต้นฉบับ, SKU, Format, Sequence, ปลายทาง, DPI, คุณภาพ JPG และจำนวนกรอบ/รายการที่เตรียมส่งออก/รายการที่ข้าม เช่น `L007-N02-01` จะแสดงเป็น `SKU=L007 | Format=N02 | Sequence=01`
- `EXPORTED`: วันเวลาที่ส่งออกภาพนั้นเสร็จ, ลำดับกรอบ/ตำแหน่ง, OID, ชื่อไฟล์และขอบเขตภาพ
- `SKIPPED`: ลำดับกรอบ/ตำแหน่ง, พิกัดและเหตุผลที่ข้าม เช่น ไม่มี Group ใน `Name` หรือข้อมูลกำกวม
- `ERROR` และ `END`: ข้อผิดพลาด รวมปัญหาการคืนสถานะ และผลรวมที่ส่งออกแล้ว ข้าม และยังไม่ได้ส่งออก

เขียนและปิด log หลังแต่ละรายการเพื่อเก็บผลก่อนหน้าไว้เมื่อภาพถัดไปส่งออกผิดพลาด หากสร้างหรือเขียน log ไม่สำเร็จจะหยุดและแจ้งข้อผิดพลาด การยกเลิกเลือกปลายทางไม่สร้าง log ชื่อ JPG ไม่มีเวลาแล้ว การส่งออกซ้ำไปโฟลเดอร์เดิมอาจเขียนทับ JPG ชื่อเดิมตามพฤติกรรม Illustrator

## พฤติกรรมที่ต้องทราบ

- ค้นหา Layer หรือ Group รวมระดับซ้อนที่ชื่อตรงกับ `frameLayerNames` และใช้ container แรกที่พบเพียงแห่งเดียว ไม่รวมกรอบจากหลาย container
- เทียบชื่อกรอบทั้งชื่อในเอกสารและใน CONFIG โดยตัดช่องว่างหัวท้ายและไม่แยกตัวพิมพ์เล็ก–ใหญ่ เช่น `CutLine`, `CUTLINE` และ ` cutline ` ตรงกัน แต่ `CutLine Backup` ไม่ตรง ช่องว่างภายในชื่อและเครื่องหมายขีดยังคงมีผล กฎนี้ใช้เฉพาะชื่อ container กรอบ ส่วน `Name`, `OID` และ `Border` ใช้กฎเดิม
- ใช้ `PathItem` ที่เป็นเส้นปิด 4 จุดและมีค่า `height > 10` เป็น Rectangle กรอบ โดยไล่ค้น Group และ sublayer ภายใน container ที่เลือก แต่ไม่ไล่ภายใน Compound Path
- ใช้เฉพาะกรอบที่พบจริงในเอกสาร ทุก SKU รวมถึง `N012` ต้องมีกรอบครบตามพื้นที่ที่ต้องการส่งออก ไม่มีการเติมพิกัดกรอบทางขวาอัตโนมัติ
- เรียงกรอบจากซ้ายไปขวาตามค่า left ของ `geometricBounds` หาก left เท่ากันจะคงลำดับจาก collection เดิม ไม่ได้เรียงเป็นแถวบนลงล่าง
- ซ่อน Layer หรือ Group กรอบที่เลือกทั้ง container ระหว่างส่งออก จึงไม่ควรเก็บงานภาพที่ต้องการส่งออกไว้ใน container เดียวกัน
- ซ่อน Layer ชื่อ `Border` ทุกตัว รวม sublayer ระหว่างส่งออก และคืน visibility เดิมของแต่ละ Layer หลังจบงานหรือเกิดข้อผิดพลาด หากไม่มี `Border` จะส่งออกตามปกติ
- ใช้ Artboard แรกเป็นพื้นที่ส่งออกชั่วคราว และเลือก Artboard นี้ให้ active ระหว่างส่งออก
- คืนขอบเขต Artboard, การแสดง Layer และ Artboard ที่ active เดิม ทั้งเมื่อสำเร็จและเมื่อส่งออกผิดพลาด หากคืนค่าใดไม่สำเร็จจะยังพยายามคืนค่าอื่นและแจ้งข้อผิดพลาด
- หากยกเลิกการเลือกโฟลเดอร์ จะไม่แก้สถานะเอกสารหรือส่งออกไฟล์
- เอกสารที่ยังไม่บันทึกใช้โฟลเดอร์ Documents เป็นจุดเริ่มต้นของหน้าต่างเลือกปลายทาง
- เลือกปลายทางใน UI ก่อนเริ่มคิว และตรวจข้อมูลการตั้งชื่อก่อนแก้ Artboard หรือ visibility
- หากส่งออกบางไฟล์แล้วเกิดข้อผิดพลาด ไฟล์ที่ส่งออกก่อนหน้ายังอยู่ ไฟล์ชื่อซ้ำอาจถูกเขียนทับตามพฤติกรรมของ Illustrator
- สคริปต์ไม่บันทึกต้นฉบับอัตโนมัติ EPS ที่สคริปต์เปิดจากคิวจะถูกปิดแบบไม่บันทึกหลัง Job ส่วนเอกสารที่เปิดอยู่ก่อนแล้วจะคงเปิดไว้ การเปลี่ยน Artboard ชั่วคราวอาจทำให้เอกสารที่คงเปิดอยู่แสดงว่าถูกแก้ไข แม้จะคืนขอบเขตเดิมแล้ว

## จุดตั้งค่าสำหรับนักพัฒนา

แก้ `CONFIG` ที่ต้นไฟล์ โดยไม่ต้องแก้ลูปส่งออก:

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `frameLayerNames` | `["CutLine", "Cut-Line", "กรอบ", "Layout", "FrameLine"]` | ชื่อ Layer หรือ Group ที่ยอมรับ รวมระดับซ้อน เทียบชื่อเต็มโดยไม่แยกตัวพิมพ์เล็ก/ใหญ่และตัดช่องว่างหัวท้าย |
| `targetDPI` | `96` | ความละเอียดภาพ คำนวณ scale เป็น `(DPI / 72) * 100` |
| `jpegQuality` | `100` | คุณภาพ JPG ช่วง 0–100 |
| `fileNumberDigits` | `3` | จำนวนหลักขั้นต่ำของลำดับชิ้นงาน เช่น `012` |
| `exportArtboardIndex` | `0` | Artboard ที่ใช้ส่งออก เริ่มนับจาก 0 และต้องมีอยู่ในเอกสาร |
| `uiWidth` | `520` | ความกว้างของช่อง path ใน ScriptUI |

ค่าปัจจุบันใช้ **96 DPI** ตามการตั้งค่าในสคริปต์ หากต้องการ 300 ให้แก้ `targetDPI` เป็น `300` ควรใช้จำนวนบวกสำหรับ DPI และจำนวนหลัก และตรวจข้อจำกัดขนาดภาพ/scale กับ Illustrator รุ่นที่ใช้งาน

## โครงสร้างและแนวทางแก้ไข

คงสคริปต์เป็นไฟล์เดียวเพื่อให้ส่งต่อและรันผ่าน Illustrator ได้โดยไม่ต้องติดตั้ง package หรือ build ส่วน helper อยู่ภายใน closure เพื่อไม่เพิ่มชื่อใน global scope

`showCaptureDialog()` สร้าง ScriptUI ในไฟล์เดียวกับกฎส่งออก `runSelection()` สร้าง Batch log ก่อนเริ่มงาน และ `executeJob()` ตรวจและส่งออกเอกสารทีละไฟล์

| ส่วน | หน้าที่ / เมื่อใดควรแก้ |
| --- | --- |
| `showCaptureDialog()` | หน้าต่างเลือกโหมด, Folder ต้นทางสำหรับ Batch และ Folder ปลายทาง |
| `executeJob()` | ตรวจเอกสาร เตรียมรายการส่งออก และ log ราย Job |
| `findFrameContainer()` | กฎการเลือก Layer หรือ Group ตาม `frameLayerNames` |
| `collectFrames()` / `copyBounds()` | เลือก Rectangle ที่ `height > 10` รวม Group ซ้อน ถ่ายสำเนาพิกัด และเรียงลำดับก่อนแก้เอกสาร |
| `getSku()` | ตรวจรหัสท้ายชื่อ job เป็น SKU 4 ตัว, รหัสรูปแบบ 1–3 ตัว และลำดับที่เป็นเลข 2 หลัก โดยไม่บังคับหรือตรวจ prefix อื่น |
| `prepareExports()` / `collectWorkGroups()` / `collectTextFrames()` | ยืนยัน Group ชิ้นงานใน `Name` จับคู่ Type ใน `OID` ตามกรอบ ใช้ `EmptyOID` เมื่อ OID ขาด และกำหนดเลขตามลำดับกรอบซ้ายไปขวา |
| `getDefaultFolder()` | โฟลเดอร์เริ่มต้น รวมกรณีเอกสารยังไม่บันทึก |
| `createExportOptions()` | ตัวเลือก JPG และ scale |
| `createOutputFile()` | ชื่อไฟล์ SKU, รหัสรูปแบบ, ลำดับที่, Order ID และลำดับตำแหน่ง |
| `createLog()` / `appendLog()` / `finishLog()` | บันทึกรายละเอียดและวันเวลาส่งออกแต่ละภาพ รายการที่ข้าม ข้อผิดพลาดและสรุปผล |
| `exportFrames()` | เก็บสถานะ ส่งออก และเรียกคืนสถานะใน `finally` |
| `restoreDocumentState()` | พยายามคืนทุกสถานะและรวบรวมข้อผิดพลาด |
| `runSelection()` / `runSelectionWithLog()` | สร้าง log สรุป เปิด EPS ทีละไฟล์ ทำงานต่อเมื่อบาง Job ผิดพลาด ปิดไฟล์ที่สคริปต์เปิด และคืนเอกสารที่ active ก่อน Batch |
| `collectEpsFiles()` | รวบรวม EPS ใต้ Folder และ Subfolder แบบ recursive |
| `createBatchLog()` | สร้าง log สรุปคิวโดยเก็บ log ชื่อซ้ำเดิมไว้ |

ข้อกำหนดในการพัฒนาต่อ:

- บันทึกไฟล์เป็น UTF-8 เพื่อรักษาชื่อ Layer และข้อความภาษาไทย
- ใช้ JavaScript แบบ ES3 สำหรับ ExtendScript: `var`, function ปกติ และลูปพื้นฐาน หลีกเลี่ยง `let`, `const`, arrow function, module import และ API จาก Node/browser
- เก็บ `#target illustrator` และคำสั่งเรียกทำงานท้ายไฟล์ไว้
- หากเพิ่มการเปลี่ยนสถานะเอกสาร ต้องเก็บค่าก่อนเปลี่ยนและเพิ่มการคืนค่าใน `restoreDocumentState()` พร้อมทดสอบกรณีผิดพลาด
