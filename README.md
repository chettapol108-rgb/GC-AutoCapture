# GC-AutoCapture

ดูแผนที่ state ของโปรแกรม หมวดปัญหา วิธีแก้ และแบบฟอร์มส่งต่องานใน [HANDOFF.md](HANDOFF.md)

Change history / ประวัติการเปลี่ยนแปลง: [CHANGELOG.md](CHANGELOG.md)

สคริปต์ Adobe Illustrator สำหรับส่งออก JPG ตามขอบเขต Rectangle ที่สูงกว่า `CONFIG.minFrameHeightCm` (ค่าเริ่มต้น 0.5 cm) ใน Layer หรือ Group ตามรายชื่อ `CONFIG.frameLayerNames` รองรับ EPS ที่เปิดอยู่และการประมวลผล EPS หลายไฟล์แบบ batch

## ScriptUI สำหรับ EPS และ Batch

แผง **Status / Diagnostic** แสดง `Job` เป็นลำดับไฟล์ EPS ที่กำลังรัน/จำนวน EPS ที่เลือก (เช่น เลือกช่วงไฟล์ที่ 5–8 จาก 10 ไฟล์ จะแสดง `1/4` เมื่อเริ่มไฟล์แรกในช่วง), `FN` เป็นชื่อ EPS ไม่รวมนามสกุล, `DATE`, `SHOP`, `SKU`, `No.` และ `Current Step` ระหว่างทำงาน ช่อง `DATE`, `SHOP`, `SKU` และ `No.` กว้างพอสำหรับค่าจากชื่อไฟล์ที่อัปเดตระหว่าง Batch ในโหมด EPS ที่เปิดอยู่ `Job` เป็น `1/1` และแสดงค่าชื่อไฟล์ก่อนกด START; ใน Batch จะแสดงค่าเมื่อเริ่มแต่ละ Job และคงค่าของ Job ล่าสุดเมื่อจบงาน หากไม่มีค่าที่อ่านได้จะแสดง `-` หน้าต่างยังเปิดหลังจบรอบ กด **START** เพื่อเริ่มรอบใหม่ได้ หรือกด **Close** เพื่อปิด

ตัวอย่าง `1102(M)-SP-L007-N02-01.eps` ให้ `FN: 1102(M)-SP-L007-N02-01`, `DATE: 1102(M)`, `SHOP: SP`, `SKU: L007 - N02` และ `No.: L007 - N02 - 01` โดยเก็บ `SKU=L007`, `sku_format=N02`, `file_sequence=01` เป็น string แยกกัน `DATE` อ่านจากส่วนแรกเมื่อเป็นเลข 4 หลักพร้อมวงเล็บตัวอักษรหนึ่งตัวหรือไม่มีก็ได้ และ `SHOP` อ่านจากส่วนที่สองเมื่อมี DATE ที่ถูกต้อง ชื่อเดิมที่ไม่มี DATE/SHOP ยังใช้ส่งออกได้ตามกฎ SKU เดิม

1. เลือก **File > Scripts > Other Script…** ใน Illustrator แล้วเปิด `GC-AutoCaputre.js`
2. เลือก **EPS ที่เปิดอยู่ปัจจุบัน** เพื่อส่งออกเอกสาร EPS ที่ active หรือเลือก **Batch** เพื่อประมวลผลหลายไฟล์
3. สำหรับ Batch กด **Browse...** ในส่วน **Folder ต้นทาง** แล้วเลือก Folder สคริปต์จะแสดงจำนวนไฟล์ `.eps` ที่พบใต้ Folder และ Subfolder ทั้งหมด พร้อมรายชื่อที่เยื้องตามระดับ Folder/Subfolder ในช่องข้อความที่เลื่อนดูได้ ลากเมาส์ครอบชื่อไฟล์ในช่องนี้แล้วกด `Ctrl+C` เพื่อคัดลอกได้ทันที ค่าเริ่มต้น **Select all** จะเลือกทุกไฟล์และทำให้ panel Optional ทั้งหมดเป็นสีเทา หากต้องการทำเฉพาะบางไฟล์ ให้เลือก **Select some...** ใน panel Folder ต้นทาง แล้วใส่ชื่อใน **START EPS** และ/หรือ **END EPS** (ใส่หรือไม่ใส่ `.eps` ก็ได้) ช่วงนี้รวมทั้งไฟล์ต้นและท้ายตามลำดับ path ที่เรียงไว้ เว้นช่องใดว่างจะเริ่มจากไฟล์แรกหรือจบที่ไฟล์สุดท้าย หากกลับไปเลือก **Select all** จะทำทุกไฟล์แม้ช่องยังมีค่าค้างอยู่ ช่องจำนวนจะแสดงจำนวนไฟล์ในช่วงที่เลือก และ `[x]` ในรายการระบุไฟล์ที่จะทำ ส่วน `[ ]` ระบุไฟล์นอกช่วง หากชื่อขอบเขตไม่พบ ซ้ำกันในหลาย Subfolder หรือ START อยู่หลัง END จะต้องแก้ชื่อก่อนเริ่มงาน
   รายการเยื้องชื่อ Folder/Subfolder ตามระดับ และใช้เส้นกิ่ง `├─` / `└─` เฉพาะบรรทัด EPS ใต้ Folder เดียวกัน โดยยังลากเมาส์เลือกข้อความได้
4. ทุกโหมดต้องเลือก **Folder ปลายทาง (Output และ Log)** ที่มีอยู่จริงก่อนกด **เริ่มส่งออก** หาก Folder ที่เลือกไม่ได้ชื่อ `.AutoCapture` สคริปต์จะสร้าง `.AutoCapture` ภายใน ใช้เก็บ log หนึ่งไฟล์ต่อรอบและสร้างโฟลเดอร์ย่อยตาม OID สำหรับ JPG
5. ใน Batch สคริปต์เปิด EPS ทีละไฟล์ ส่งออกและคืนสถานะ แล้วปิดไฟล์ที่สคริปต์เปิดเองโดยไม่บันทึกก่อนทำไฟล์ถัดไป หากไฟล์นั้นเปิดอยู่แล้วจะใช้เอกสารเดิมและไม่ปิดให้
6. เมื่อจบรอบ จะแสดงจำนวน Job, JPG, รายการที่ข้าม และตำแหน่ง `AutoCapture_Log_*.txt` จากนั้นปรับ Folder หรือช่วงไฟล์แล้วกด **START** อีกครั้งได้ โดยแต่ละรอบสร้าง log ใหม่

สคริปต์ตรวจจำนวน EPS และช่วงไฟล์ในหน้าต่างก่อนเริ่มงาน โดยไม่สร้าง log หากชื่อขอบเขตไม่ถูกต้อง หลังยืนยัน Destination จะสร้าง log เดียวก่อนตรวจข้อมูลหรือเปิด EPS เพื่อบันทึกกรณีไม่พบไฟล์ การเปิด EPS การตรวจข้อมูล การส่งออก การคืนสถานะ และการปิดเอกสารก่อนแสดง Error Alert หากยังไม่ได้เลือก Destination หรือเลือก path ไม่ถูกต้อง ScriptUI จะแสดงข้อความในหน้าต่างแทน Alert เพราะยังไม่มีตำแหน่งที่เขียน log ได้

Batch จะทำไฟล์ถัดไปต่อเมื่อ Job หนึ่งผิดพลาด และสรุปข้อผิดพลาดทั้งหมดเมื่อจบรอบ หากไม่พบ EPS ใต้ Folder ที่เลือกจะบันทึกเหตุผลใน log แล้วแสดง Error Alert ส่งต่อ `GC-AutoCaputre.js` ไฟล์เดียวได้ เมื่อชื่อ JPG ซ้ำกับไฟล์ที่มีอยู่ สคริปต์จะเติม `_02`, `_03` ตามลำดับแทนการเขียนทับ

## เริ่มใช้งานผ่าน Illustrator (เอกสารที่เปิดอยู่)

1. เปิดเอกสาร EPS ใน Illustrator และเตรียม Layer หรือ Group ชื่อตรงกับ `CONFIG.frameLayerNames`: `CutLine`, `Cut-Line`, `กรอบ`, `Layout` หรือ `FrameLine` โดยไม่แยกตัวพิมพ์เล็ก–ใหญ่และตัดช่องว่างหัวท้ายก่อนเทียบ
2. วาง Rectangle ที่สูงกว่า 0.5 cm ไว้ภายใน container นี้ รวม Group ซ้อนหรือ sublayer ได้
3. ตั้งชื่อเอกสารตาม job เช่น `1028(M)-TT-N012-03-01.eps` และเตรียม Layer `Name` หรือ `NAME` กับ `OID` ตามรายละเอียดด้านล่าง
4. เลือก **File > Scripts > Other Script…** แล้วเปิด `GC-AutoCaputre.js`
5. เลือก **EPS ที่เปิดอยู่ปัจจุบัน**, เลือก Folder ปลายทาง แล้วกด **เริ่มส่งออก** จะได้ไฟล์ เช่น `N012-03-01-12345678901234567890-003.jpg` พร้อม log หนึ่งไฟล์สำหรับรอบนั้น

ชื่อไฟล์ปัจจุบันสะกดว่า **GC-AutoCaputre.js** ตามไฟล์ในโปรเจกต์ โปรดใช้ชื่อนี้ในการติดตั้งและทดสอบ

ปัจจุบันใช้ไฟล์นามสกุล **`.js`** สำหรับพัฒนาและส่งมอบ สามารถเลือกไฟล์นี้ผ่านเมนูข้างต้นได้โดยใช้ชื่อเดิม สคริปต์ยังทำงานด้วย Adobe Illustrator ExtendScript และใช้ไวยากรณ์ JavaScript แบบ ES3

## ชื่อไฟล์และการจับคู่ Order ID

รูปแบบส่งออกคือ `[รหัสจากชื่อเอกสาร]-[Order ID]-ลำดับกรอบ.jpg` โดยรหัสจากชื่อเอกสารมี 4 แบบ: `SKU-รหัสรูปแบบ-ลำดับที่`, `SKU-รหัสรูปแบบ`, `SKU-ลำดับที่` หรือ `SKU`

- **SKU, รหัสรูปแบบ และลำดับที่**: ชื่อเอกสารต้องลงท้ายด้วย SKU ที่เป็นตัวอักษรอังกฤษ 1 ตัวตามด้วยเลข 3 หลัก เช่น `N003`, `L007` หรือ `M006` รหัสรูปแบบที่อยู่เดี่ยวหรือก่อนลำดับเป็นอักษรอังกฤษ 1 ตัว (`A`, `B`, `C`, `O`, `Q`) หรืออักษรอังกฤษตามด้วยเลข 1–2 หลัก (`N01`, `R1`, `V4`, `F12`) รหัสรูปแบบตัวเลข 1–3 หลักยังรับเมื่อมีลำดับต่อท้ายเพื่อรองรับงานเดิม เช่น `N012-11-01` ลำดับเป็นเลข 2 หลัก; หากต่อท้าย SKU ด้วยเลข 2 หลักเพียงส่วนเดียว จะตีความเป็นลำดับ เช่น `N003-01` ตัวอย่างที่รับ: `N003.eps`, `N003-A.eps`, `N003-R1.eps`, `N003-01.eps` และ `1102(M)-SP-L007-N02-01.eps` โดยไม่บังคับหรือตรวจเดือน/วันและ prefix ที่อยู่ก่อน SKU
- **ลำดับกรอบ**: คัด Rectangle ที่สูงไม่เกิน 0.5 cm ออกก่อน แล้วเรียงกรอบที่เหลือตาม Y ของขอบบนจากบนลงล่าง หาก Y เท่ากันจะเรียงตาม X ของขอบซ้ายจากซ้ายไปขวา จึงได้ลำดับแบบอ่านทีละแถวจากบนซ้ายไปขวาแล้วลงแถวถัดไป หาก X และ Y เท่ากันจะใช้ลำดับวัตถุเดิม พิกัด X/Y เป็นหน่วย points จาก `geometricBounds` ของ Illustrator นับจาก 1 ก่อนคัดกรอบที่ข้าม กรอบที่ถูกคัดออกไม่กินลำดับ เช่น 3 Rectangle ที่มี 2 อันสูงไม่เกิน 0.5 cm จะนับเป็น 1 กรอบ ใช้ลำดับกรอบเป็นเลขท้ายชื่อ JPG โดยเติมศูนย์ตาม `fileNumberDigits` เช่น กรอบที่ 3 ได้ `003` ไม่อ่านหรือตรวจตัวเลขหลัง `N` ในชื่อวัตถุ
- **Layer `Name` หรือ `NAME`**: แต่ละกรอบต้องมี `TextFrame` (Type) หรือ Group ที่ตั้งชื่อไว้ อย่างน้อยหนึ่งรายการใน Layer ที่เลือก รวมระดับซ้อนกัน ชื่อ Type เป็นค่าใดก็ได้ ส่วน Group ต้องมีชื่อที่ไม่ว่าง ใช้จุดกึ่งกลาง `geometricBounds` ของวัตถุนั้นตรวจว่าอยู่ในกรอบใด โดยขอบร่วมเป็นของกรอบทางขวาหรือด้านล่าง หากชื่อวัตถุ Type ลงท้ายด้วย `-BC` หรือ `_BC` (รวมตัวพิมพ์เล็ก เช่น `-bc`, `_bc`) อักขระทุกตัวใน Type นั้นต้องใช้ฟอนต์ `Libre Barcode 128 Text` สไตล์ `Regular` จึงจะส่งออกกรอบนั้น
- **Order ID**: ค้นวัตถุ Type ภายใน Layer `OID` รวม Group ซ้อนกัน แล้วใช้จุดกึ่งกลาง `geometricBounds` ตรวจว่า OID อยู่ในกรอบส่งออกใด ไม่ใช้ลำดับซ้อนใน Layers panel อ่านค่าจาก **Name ของวัตถุ** ก่อน หาก Name ว่างจะอ่าน `contents` รองรับเลขล้วนหรืออักษรอังกฤษผสมตัวเลข เช่น `123456`, `ABC123` และ `123ABC` โดยเก็บเป็นข้อความเพื่อรักษาศูนย์นำหน้าและเลขออเดอร์ยาว
- **การจับคู่**: แต่ละกรอบต้องพบ Type หรือ Group ที่ตั้งชื่อไว้ใน `Name` หรือ `NAME` อย่างน้อยหนึ่งรายการและ OID ที่มีค่าเพียงหนึ่งรายการในพื้นที่เดียวกัน หากมี TextFrame ของ OID ที่ทั้ง Name และ contents ว่างอยู่ด้วย จะมองข้ามตัวว่างและใช้ OID ที่มีค่า เลขท้ายชื่อไฟล์ใช้ลำดับกรอบเดิม เช่น กรอบที่ 3 ได้ `003` แม้กรอบก่อนหน้าถูกข้าม และเลขตั้งแต่ 1000 ขึ้นไปไม่ถูกตัด
- **วันเวลา**: บันทึกใน log แทนชื่อ JPG ใช้เวลาท้องถิ่นของเครื่อง โดยอ่านเวลาที่ส่งออกแต่ละภาพเสร็จใหม่หลัง `exportFile` สำเร็จ

หากมี TextFrame ของ OID ว่างเพียงอันเดียวในกรอบ หรือ OID ที่เลือกมีค่าแต่ไม่ใช่เลขล้วน/อักษรอังกฤษผสมตัวเลข สคริปต์จะยังส่งออกภาพและใช้ `EmptyOID` แทน Order ID ในชื่อไฟล์ เช่น `N012-11-01-EmptyOID-002.jpg` หากไม่มี Layer ที่ต้องใช้ ไม่มี Type หรือ Group ที่ตั้งชื่อไว้ใน `Name` หรือ OID ในพื้นที่นั้น มี OID ที่มีค่าหลายรายการ มี TextFrame ว่างหลายรายการโดยไม่มี OID ที่มีค่า marker ใน `Name`/OID ที่เลือกอยู่ในหลายกรอบที่ซ้อนกัน หรือ Type marker ชื่อลงท้าย `-BC`/`_BC` ใช้ฟอนต์ไม่ตรงหรือไม่มีอักขระให้ตรวจ จะข้ามกรอบพร้อมเหตุผลใน log แม้มี marker อื่นในกรอบเดียวกัน หากข้ามทั้งหมดจะยังเก็บ log ที่ปลายทางโดยไม่แก้ Artboard หรือ visibility เมื่อจบคิวจะแสดงจำนวนภาพที่ส่งออกและข้ามพร้อมตำแหน่ง log

ใช้ชื่อ Layer `Name` หรือ `NAME` สำหรับ marker และ `OID` สำหรับ Order ID ตรงตามตัวพิมพ์ โดยค้น sublayer ได้ หากมีทั้ง `Name` และ `NAME` จะใช้ Layer แรกที่พบ สามารถเก็บ Type และ Group ที่ตั้งชื่อไว้ใน Group ซ้อนกันได้ ส่วน OID ยังต้องเป็น TextFrame และต้องวางจุดกึ่งกลางภายในกรอบที่ต้องการจับคู่

## บันทึกการส่งออก

หลังคลิก **เริ่มส่งออก** จะสร้างไฟล์ UTF-8 เพียงหนึ่งไฟล์ต่อรอบชื่อ `AutoCapture_Log_YYYYMMDD_HHMMSS.txt` ใน `.AutoCapture` ส่วน JPG จะอยู่ในโฟลเดอร์ย่อยตาม OID โดยเวลาในชื่อ log คือเวลาเริ่มรอบ หากชื่อซ้ำภายในวินาทีเดียวจะเติม `_02`, `_03` เพื่อเก็บประวัติเดิม การเลือกปลายทางอย่างเดียวยังไม่สร้าง log

- `START` และ `DISCOVERED`: โหมดการทำงาน, ปลายทาง จำนวน EPS ทั้งหมดและจำนวนที่เลือกในโหมด Batch พร้อมชื่อ START EPS / END EPS
- `JOB START` และ `JOB INFO`: พาธต้นฉบับ, SKU, รหัสรูปแบบ (ถ้ามี), ลำดับ (ถ้ามี), DPI, คุณภาพ JPG และจำนวนกรอบ/รายการที่เตรียมส่งออก/รายการที่ข้าม เช่น `L007-N02-01` แสดง `SKU: L007 | N02 | 01`, `N003-A` แสดง `SKU: N003 | A` และ `N003-01` แสดง `SKU: N003 | 01`
- `EXPORTED`: วันเวลาที่ส่งออกภาพนั้นเสร็จ, ลำดับกรอบ (`Frame` และ `Work`), OID, ชื่อไฟล์, X/Y ของขอบซ้ายบนและขอบเขตภาพ (`Bounds`)
- `SKIPPED`: ลำดับกรอบ, X/Y ของขอบซ้ายบน, ขอบเขตภาพและเหตุผลที่ข้าม เช่น ไม่มี Type ใน `Name` ไม่มี OID หรือข้อมูลกำกวม
- `JOB END`: สถานะและจำนวนภาพที่ส่งออก ข้าม และยังไม่ได้ส่งออกของ Job นั้น
- `ERROR`, `END` และ `ALERT ERROR`: ข้อผิดพลาด รวมปัญหาการคืนสถานะ และผลรวมทั้งรอบ

เขียนและปิด log หลังแต่ละรายการเพื่อเก็บผลก่อนหน้าไว้เมื่อภาพถัดไปส่งออกผิดพลาด หากสร้างหรือเขียน log ไม่สำเร็จจะหยุดและแจ้งข้อผิดพลาด การยกเลิกเลือกปลายทางไม่สร้าง log ชื่อ JPG ไม่มีเวลาแล้ว และเมื่อชื่อซ้ำจะเติมเลขท้ายเพื่อรักษา JPG เดิม

## พฤติกรรมที่ต้องทราบ

- ค้นหา Layer หรือ Group รวมระดับซ้อนที่ชื่อตรงกับ `frameLayerNames` และใช้ container แรกที่พบเพียงแห่งเดียว ไม่รวมกรอบจากหลาย container
- เทียบชื่อกรอบทั้งชื่อในเอกสารและใน CONFIG โดยตัดช่องว่างหัวท้ายและไม่แยกตัวพิมพ์เล็ก–ใหญ่ เช่น `CutLine`, `CUTLINE` และ ` cutline ` ตรงกัน แต่ `CutLine Backup` ไม่ตรง ช่องว่างภายในชื่อและเครื่องหมายขีดยังคงมีผล กฎนี้ใช้เฉพาะชื่อ container กรอบ ส่วน Layer marker รับเฉพาะ `Name` หรือ `NAME` และ `OID` กับ `Border` ใช้กฎเดิม
- ใช้ `PathItem` ที่เป็นเส้นปิด 4 จุดและสูงกว่า `minFrameHeightCm` (ค่าเริ่มต้น 0.5 cm) เป็น Rectangle กรอบ โดยไล่ค้น Group และ sublayer ภายใน container ที่เลือก แต่ไม่ไล่ภายใน Compound Path; สคริปต์แปลง cm เป็น points ก่อนเทียบกับ `height` ของ Illustrator API
- ใช้เฉพาะกรอบที่พบจริงในเอกสาร ทุก SKU รวมถึง `N012` ต้องมีกรอบครบตามพื้นที่ที่ต้องการส่งออก ไม่มีการเติมพิกัดกรอบทางขวาอัตโนมัติ
- เรียงกรอบจากซ้ายไปขวาตามค่า left ของ `geometricBounds` หาก left เท่ากันจะคงลำดับจาก collection เดิม ไม่ได้เรียงเป็นแถวบนลงล่าง
- ซ่อน Layer หรือ Group กรอบที่เลือกทั้ง container ระหว่างส่งออก จึงไม่ควรเก็บงานภาพที่ต้องการส่งออกไว้ใน container เดียวกัน
- ซ่อน Layer ชื่อ `Border` ทุกตัว รวม sublayer ระหว่างส่งออก และคืน visibility เดิมของแต่ละ Layer หลังจบงานหรือเกิดข้อผิดพลาด หากไม่มี `Border` จะส่งออกตามปกติ
- ใช้ Artboard แรกเป็นพื้นที่ส่งออกชั่วคราว และเลือก Artboard นี้ให้ active ระหว่างส่งออก
- คืนขอบเขต Artboard, การแสดง Layer และ Artboard ที่ active เดิม ทั้งเมื่อสำเร็จและเมื่อส่งออกผิดพลาด หากคืนค่าใดไม่สำเร็จจะยังพยายามคืนค่าอื่นและแจ้งข้อผิดพลาด
- หากยกเลิกการเลือกโฟลเดอร์ จะไม่แก้สถานะเอกสารหรือส่งออกไฟล์
- เอกสารที่ยังไม่บันทึกใช้โฟลเดอร์ Documents เป็นจุดเริ่มต้นของหน้าต่างเลือกปลายทาง
- เลือกปลายทางใน UI ก่อนเริ่มคิว และตรวจข้อมูลการตั้งชื่อก่อนแก้ Artboard หรือ visibility
- หากส่งออกบางไฟล์แล้วเกิดข้อผิดพลาด ไฟล์ที่ส่งออกก่อนหน้ายังอยู่ หากชื่อซ้ำจะเติม `_02`, `_03` ตามลำดับแทนการเขียนทับ
- สคริปต์ไม่บันทึกต้นฉบับอัตโนมัติ EPS ที่สคริปต์เปิดจากคิวจะถูกปิดแบบไม่บันทึกหลัง Job ส่วนเอกสารที่เปิดอยู่ก่อนแล้วจะคงเปิดไว้ การเปลี่ยน Artboard ชั่วคราวอาจทำให้เอกสารที่คงเปิดอยู่แสดงว่าถูกแก้ไข แม้จะคืนขอบเขตเดิมแล้ว

## จุดตั้งค่าสำหรับนักพัฒนา

แก้ `CONFIG` ที่ต้นไฟล์ โดยไม่ต้องแก้ลูปส่งออก:

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `frameLayerNames` | `["CutLine", "Cut-Line", "กรอบ", "Layout", "FrameLine"]` | ชื่อ Layer หรือ Group ที่ยอมรับ รวมระดับซ้อน เทียบชื่อเต็มโดยไม่แยกตัวพิมพ์เล็ก/ใหญ่และตัดช่องว่างหัวท้าย |
| `targetDPI` | `96` | ความละเอียดภาพ คำนวณ scale เป็น `(DPI / 72) * 100` |
| `jpegQuality` | `100` | คุณภาพ JPG ช่วง 0–100 |
| `minFrameHeightCm` | `0.5` | ความสูงขั้นต่ำของกรอบ หน่วย cm; ต้องสูงกว่าเกณฑ์นี้จึงถูกนับ |
| `fileNumberDigits` | `3` | จำนวนหลักขั้นต่ำของลำดับกรอบ เช่น `012` |
| `exportArtboardIndex` | `0` | Artboard ที่ใช้ส่งออก เริ่มนับจาก 0 และต้องมีอยู่ในเอกสาร |
| `outputFolderName` | `.AutoCapture` | ชื่อ Folder ที่เก็บ JPG และ log จริง หากปลายทางที่เลือกใช้ชื่ออื่นจะสร้าง Folder นี้ภายใน |
| `barcodeFontFamily` / `barcodeFontStyle` | `Libre Barcode 128 Text` / `Regular` | ฟอนต์ที่ Type marker ชื่อลงท้าย `-BC` หรือ `_BC` ต้องใช้ทุกอักขระ |
| `uiWidth` | `520` | ความกว้างของช่อง path ใน ScriptUI |

ค่าปัจจุบันใช้ **96 DPI** ตามการตั้งค่าในสคริปต์ หากต้องการ 300 ให้แก้ `targetDPI` เป็น `300` ควรใช้จำนวนบวกสำหรับ DPI และจำนวนหลัก และตรวจข้อจำกัดขนาดภาพ/scale กับ Illustrator รุ่นที่ใช้งาน

## โครงสร้างและแนวทางแก้ไข

คงสคริปต์เป็นไฟล์เดียวเพื่อให้ส่งต่อและรันผ่าน Illustrator ได้โดยไม่ต้องติดตั้ง package หรือ build ส่วน helper อยู่ภายใน closure เพื่อไม่เพิ่มชื่อใน global scope

`showCaptureDialog()` สร้าง ScriptUI ในไฟล์เดียวกับกฎส่งออก `runSelection()` สร้าง log เดียวก่อนเริ่มงาน และ `executeJob()` ตรวจและส่งออกเอกสารทีละไฟล์

| ส่วน | หน้าที่ / เมื่อใดควรแก้ |
| --- | --- |
| `showCaptureDialog()` / `getEpsTreeText()` | หน้าต่างเลือกโหมด, Folder ต้นทางสำหรับ Batch, รายชื่อ EPS ที่เลือกข้อความได้ และ Folder ปลายทาง |
| `executeJob()` | ตรวจเอกสาร เตรียมรายการส่งออก และเขียนรายละเอียด Job ลง log กลาง |
| `findFrameContainer()` | กฎการเลือก Layer หรือ Group ตาม `frameLayerNames` |
| `collectFrames()` / `copyBounds()` | เลือก Rectangle ที่สูงกว่า `minFrameHeightCm` รวม Group ซ้อน ถ่ายสำเนาพิกัด และเรียงลำดับก่อนแก้เอกสาร |
| `getSku()` | ตรวจท้ายชื่อ job เป็น SKU ตัวอังกฤษ 1 ตัวและเลข 3 หลัก โดยอาจมีรหัสรูปแบบ, ลำดับเลข 2 หลัก หรือทั้งคู่ และไม่บังคับหรือตรวจ prefix อื่น |
| `prepareExports()` / `collectNameMarkers()` / `collectTextFrames()` | ตรวจ Type หรือ Group ที่ตั้งชื่อไว้ใน `Name` หรือ `NAME` และ Type ใน `OID` ตามตำแหน่ง ใช้ลำดับกรอบเป็นเลขท้ายไฟล์ แล้วข้ามกรอบที่ข้อมูลไม่ครบหรือกำกวม |
| `getDefaultFolder()` | โฟลเดอร์เริ่มต้น รวมกรณีเอกสารยังไม่บันทึก |
| `ensureOutputFolder()` | ตรวจชื่อ Folder ปลายทาง และสร้าง Folder ลูกตาม `outputFolderName` เมื่อชื่อไม่ตรง |
| `createExportOptions()` | ตัวเลือก JPG และ scale |
| `createOutputFile()` | ใช้รหัสจากชื่อเอกสารตามที่มีจริง ตามด้วย Order ID และลำดับกรอบ พร้อมเติมเลขท้ายเมื่อชื่อซ้ำ |
| `createLog()` / `appendLog()` | สร้าง log หนึ่งไฟล์ต่อรอบและบันทึกวันเวลาส่งออกแต่ละภาพ รายการที่ข้าม ข้อผิดพลาดและสรุปผล |
| `exportFrames()` | เก็บสถานะ ส่งออก และเรียกคืนสถานะใน `finally` |
| `restoreDocumentState()` | พยายามคืนทุกสถานะและรวบรวมข้อผิดพลาด |
| `runSelection()` / `runSelectionWithLog()` | ใช้ log เดียว เปิด EPS ทีละไฟล์ ทำงานต่อเมื่อบาง Job ผิดพลาด ปิดไฟล์ที่สคริปต์เปิด และคืนเอกสารที่ active ก่อน Batch |
| `collectEpsFiles()` | รวบรวม EPS ใต้ Folder และ Subfolder แบบ recursive |

ข้อกำหนดในการพัฒนาต่อ:

- บันทึกไฟล์เป็น UTF-8 เพื่อรักษาชื่อ Layer และข้อความภาษาไทย
- ใช้ JavaScript แบบ ES3 สำหรับ ExtendScript: `var`, function ปกติ และลูปพื้นฐาน หลีกเลี่ยง `let`, `const`, arrow function, module import และ API จาก Node/browser
- เก็บ `#target illustrator` และคำสั่งเรียกทำงานท้ายไฟล์ไว้
- หากเพิ่มการเปลี่ยนสถานะเอกสาร ต้องเก็บค่าก่อนเปลี่ยนและเพิ่มการคืนค่าใน `restoreDocumentState()` พร้อมทดสอบกรณีผิดพลาด

   ตรวจชื่อ `N003.eps`, `N003-A.eps`, `N003-R1.eps`, `N003-N01-01.eps`, `N003-01.eps`, `N012-11-01.eps` และ `1102(M)-SP-L007-N02-01.eps` ว่าผ่าน โดย log ต้องแยก `N003-A` เป็น `SKU: N003 | A`, `N003-01` เป็น `SKU: N003 | 01` และชื่อสุดท้ายเป็น `SKU: L007 | N02 | 01` ตรวจว่า `003N`, `N03`, `1234`, `N003-ABC`, `N003-1A`, รหัสรูปแบบที่ว่างหรือยาวเกิน 3 ตัว และลำดับที่ซึ่งไม่ใช่เลข 2 หลักไม่ผ่าน
2. ตรวจว่าเส้นกรอบไม่ติดภาพ ขนาดภาพถูกต้อง และคุณภาพ/DPI ตรงค่าตั้ง
3. ลองทั้ง Layer และ Group ชื่อ `กรอบ` หรือ `Layout` รวม Group ซ้อนและกรณีมีหลายชื่อ ตรวจว่าใช้ container แรกเพียงแห่งเดียว และไม่ใช้เส้นเปิด/วัตถุสูงไม่เกิน 0.5 cm เป็นกรอบ
   วางกรอบ 2 แถว แถวละ 2 อัน โดย Y ขอบบนในแถวเดียวกันเท่ากัน ตรวจว่าลำดับเป็นบนซ้าย, บนขวา, ล่างซ้าย, ล่างขวา แม้ล่างซ้ายมี X น้อยกว่าบนขวา และค่า X/Y ใน `EXPORTED` หรือ `SKIPPED` ตรงกับ `geometricBounds` ของกรอบนั้น
4. เปิดเอกสารหลาย Artboard โดย active Artboard อื่นก่อนรัน ตรวจภาพและการคืน Artboard ที่ active เดิม
5. ลองยกเลิกเลือกโฟลเดอร์ เอกสารยังไม่บันทึก Layer ที่ซ่อนอยู่ และปลายทางที่เขียนไม่ได้ ตรวจข้อความและสถานะที่คืนมา
6. ตรวจซ้ำกับ EPS จริงที่ใช้ในงาน โดยเฉพาะ Group, Compound Path, clipping และเอฟเฟ็กต์ที่อาจมีขอบเขตภาพเกิน `geometricBounds`
7. เปิด `N012` ที่มีกรอบจริงจำนวนที่ทราบ ตรวจว่าจำนวนกรอบใน log ตรงกับ Rectangle ที่ผ่านเงื่อนไข และไม่มีพื้นที่ทางขวาถูกเติมเพิ่ม ทดลอง Rectangle สูง 0.49, 0.5 และ 0.51 cm โดย 0.49 และ 0.5 cm ต้องไม่ถูกนับหรือกินลำดับ ส่วน 0.51 cm ต้องถูกนับ ทดลอง 3 Rectangle ที่มี 2 อันสูงไม่เกิน 0.5 cm แล้วตรวจว่า log นับ 1 กรอบและใช้เลขท้าย `001` ทดลองเพิ่มหรือลบ Rectangle เพื่อให้จำนวนเปลี่ยนตามกรอบจริงเท่านั้น ทดลองไฟล์ `...1103-SP-L007-N06-01.eps` ที่เคยพบกรอบแนวนอนสูง 0.5 cm ว่าไม่กินเลข `002` และภาพ 6 กรอบลงท้าย `001`–`006`
   สำหรับการเทียบชื่อกรอบ ให้ลอง `CutLine`, `CUTLINE`, ` cutline ` และ ` กรอบ ` ทั้ง Layer และ Group รวมระดับซ้อน ต้องเลือกได้เหมือนกัน ลองค่าที่มีช่องว่างหัวท้ายใน CONFIG ด้วย และตรวจว่า `CutLine Backup` หรือ `Cut Line` ไม่ตรงกับ `CutLine` เมื่อมีหลาย container ที่ตรงหลังปรับชื่อ ต้องยังใช้ตัวแรกตามลำดับค้นหา
8. ทดลอง OID แบบเลขล้วนและอักษรผสมตัวเลข เช่น `123456` และ `ABC123` จากนั้นลบค่า OID ในกรอบหนึ่งจากทั้ง Name และ contents โดยยังเก็บ TextFrame ไว้ ตรวจว่ายังส่งออกกรอบนั้นด้วย `EmptyOID` เพิ่ม TextFrame ว่างอีกอันในกรอบที่มี OID จริง ตรวจว่าเลือก OID จริงและส่งออกเพียงหนึ่งภาพ ลอง OID จริงสองอันร่วมกับตัวว่าง และลอง TextFrame ว่างสองอันโดยไม่มี OID จริง ตรวจว่าข้ามเป็นข้อมูลกำกวม แล้วลบ TextFrame ของ OID หรือ Type/Group ที่ตั้งชื่อไว้ใน Layer `Name` ของอีกกรอบเพื่อตรวจว่าเฉพาะกรอบที่ข้อมูลหายถูกข้าม ลองใช้ Group ชื่อ `N2` ที่มีแต่ PathItem เป็น marker, Group ไม่ตั้งชื่อ, Group ซ้อน และ Type ใน Group แล้วตรวจตำแหน่งจุดกึ่งกลาง ลองวาง marker ในกรอบซ้อนเพื่อตรวจว่าข้ามเป็นข้อมูลกำกวม
   ตั้งชื่อ Type marker เป็น `N1-BC`, `N1_BC`, `N1-bc`, `N1_bc` แล้วลองฟอนต์ `Libre Barcode 128 Text Regular`, ฟอนต์อื่น, ตัวอักษรผสมหลายฟอนต์ และ Type ว่าง ตรวจว่าส่งออกเฉพาะเมื่อทุกอักขระใช้ฟอนต์ที่กำหนด และกรอบที่ข้ามมีเหตุผลใน log; Type ชื่อไม่ลงท้าย BC และ Group marker ไม่ต้องตรวจฟอนต์
9. เปิด ScriptUI แล้วลองทั้ง **EPS ที่เปิดอยู่ปัจจุบัน** และ **Batch** เลือก Folder ต้นทางที่มี EPS ในหลายระดับ Subfolder ตรวจจำนวนทั้งหมดและรายชื่อทุกไฟล์ที่เยื้องระดับและเลื่อนดูได้ ลากเมาส์ครอบชื่อไฟล์ในรายการแล้วกด `Ctrl+C` ตรวจข้อความที่คัดลอก ตรวจว่าค่าเริ่มต้นเป็น **Select all** และ panel Optional ทั้งหมดเป็นสีเทา จากนั้นเลือก **Select some...** เพื่อตรวจว่ากรอก START EPS / END EPS ได้ และตรวจ `[x]`/`[ ]` เมื่อเปลี่ยนช่วงทั้งแบบเว้นว่าง กรอกเพียงช่องเดียว ใส่ชื่อที่ไม่มีจริง ชื่อซ้ำข้าม Subfolder และช่วงกลับด้าน ตรวจว่าไฟล์ต้นกับท้ายถูกรวมในคิว แล้วกลับไปเลือก Select all โดยยังมีชื่อค้างอยู่ ตรวจว่ากลับไปเลือกทุกไฟล์และ panel Optional เป็นสีเทา จากนั้นเลือก Folder ปลายทางที่มี path ภาษาไทย/ช่องว่าง ตรวจว่าเมื่อเลือก Folder ชื่ออื่นจะสร้าง `.AutoCapture` ภายใน แต่เมื่อเลือก `.AutoCapture` โดยตรงต้องไม่สร้างซ้อน ส่งออกซ้ำโดยกด START ในหน้าต่างเดิมแล้วตรวจว่า JPG เดิมยังอยู่และไฟล์ใหม่เติม `_02` พร้อม log แยกรอบ ตรวจการปิดหน้าต่างก่อนเริ่มว่าต้องไม่สร้าง log และตรวจว่า path ที่ไม่ถูกต้องแสดงข้อความใน UI โดยไม่ใช้ Alert
10. รัน Batch อย่างน้อยสอง Job และเลือกช่วงที่ไม่เริ่มจากไฟล์แรก ตรวจว่า `Job` เริ่มที่ `1` และแสดงจำนวน EPS ที่เลือกเป็นตัวหาร และ `Current Step` แสดงข้อความครบทุกขั้นตอน ตรวจว่าเปิดครั้งละหนึ่ง EPS และปิดแบบไม่บันทึกก่อนเปิดไฟล์ถัดไป ตรวจ Job/OID/ชื่อ JPG และ log เดียวที่มีรายละเอียดทุก Job ลองให้ export ผิดพลาด ไฟล์เปิดไม่ได้ และ Folder ไม่มี EPS ตรวจว่า Error Alert ทุกกรณีอ้างถึง log และเอกสารที่ผู้ใช้เปิดไว้ไม่ถูกปิด ลองเริ่มสองรอบในวินาทีเดียวกันเพื่อตรวจชื่อ `_02` และจำลองปลายทางที่เขียน log ไม่ได้เพื่อตรวจว่าคิวหยุด
