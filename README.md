## ScriptUI สำหรับ EPS และ Batch

สคริปต์เขียน debug log ตั้งแต่เริ่มทำงานที่ `G:\047-Pearl\Work\Design\SITKA\autoCapture_Debugger\AutoCapture_Debug_YYYYMMDD_hhmmss.log` โดยปรับโฟลเดอร์ได้ที่ `CONFIG.debugFolderPath` ชื่อใช้เวลาเริ่มสคริปต์ และการเริ่มในวินาทีเดียวกันจะเขียนต่อไฟล์เดียวกัน `08` หมายถึงเรียกแสดง dialog แล้ว และ `09` หมายถึง dialog ปิดแล้ว หากเข้าถึงโฟลเดอร์หรือเขียน log ไม่ได้ สคริปต์จะทำงานต่อโดยอาจไม่มี debug log; session log อยู่ใน `<output>/logs/sessions` ตามเดิม

ระหว่างตั้งค่าโหมดเริ่มต้น log `MODE` แยกการตั้ง panel, จำนวนไฟล์ และข้อมูล Diagnostic; เมื่อหน้าต่างแสดงแล้ว log `UI` คร่อม `dialog.update()` การอัปเดตหน้าต่างก่อน `dialog.show()` ถูกข้าม หากค้างก่อนเห็นหน้าต่าง ให้ดูบรรทัด `MODE` ล่าสุดใน debug log แล้วลองสลับ Single/Batch หลังหน้าต่างเปิดเพื่อตรวจว่า panel และสถานะเปลี่ยนตามโหมด
ตอนเปิดหน้าต่างและสลับโหมดจะยังไม่อ่านชื่อเอกสาร จึงแสดง `FN`, `DATE`, `SHOP`, `SKU` และ `No.` เป็น `-` จนกด START จากนั้น log `START` จะแยกการอ่านชื่อกับการแยกข้อมูล หากหยุดที่ `Before reading active document name` คือค้างขณะอ่านชื่อจาก Illustrator; หากหยุดที่ `before parsing` คือค้างขณะแยกชื่อ
เมื่อ `START | After reading active document name; before parsing` เป็นบรรทัดล่าสุด ให้ดู `NAME` ถัดไปเพื่อแยกการตัดนามสกุล, การหา SKU, การแยก SKU และ DATE/SHOP โดย `length` คือความยาวชื่อเอกสาร

หน้าต่าง ScriptUI เป็น `dialog` ต้องปิดหน้าต่างก่อนกลับไปปิดหรือเปิดเอกสารใน Illustrator หากต้องการส่งออกเอกสารอีกไฟล์ ให้เปิดไฟล์นั้นแล้วเรียกสคริปต์ใหม่ Single Mode ใช้เอกสารที่ active ตอนเปิด dialog และระหว่างที่ dialog เปิดอยู่จะเปลี่ยนเอกสารไม่ได้ หลังจบรอบสามารถกด **START** อีกครั้งกับงานเดิม หรือกด **Cancel** / **Close** เพื่อปิดหน้าต่าง

แผง **Status / Diagnostic** แสดง `Job`, `FN`, `DATE`, `SHOP`, `SKU`, `No.` และ `Current Step` โดย SKU เป็นรหัสเต็มก่อนเลขลำดับท้าย เช่น `N017-01-S` หรือ `PRE-FLX-0001` ส่วน No. รวมเลขลำดับท้ายด้วย ใน Single Mode ข้อมูลชื่อไฟล์แสดงหลังกด START; ใน Batch จะแสดงค่าเมื่อเริ่มแต่ละ Job หากไม่มีค่าที่อ่านได้จะแสดง `-` หน้าต่างยังเปิดหลังจบรอบ กด **START** เพื่อเริ่มรอบใหม่ได้ หรือกด **Close** เพื่อปิด

ตัวอย่าง `1102(M)-SP-L007-N02-01.eps` ให้ `FN: 1102(M)-SP-L007-N02-01`, `DATE: 1102(M)`, `SHOP: SP`, `SKU: L007-N02` และ `No.: L007-N02-01` โดยเก็บ SKU และลำดับเป็น string แยกกัน `DATE` อ่านจากส่วนแรกเมื่อเป็นเลข 4 หลักพร้อมวงเล็บตัวอักษรหนึ่งตัวหรือไม่มีก็ได้ และ `SHOP` อ่านจากส่วนที่สองเมื่อมี DATE ที่ถูกต้อง หากไม่พบ pattern DATE จะแสดง `0000` ก่อนเริ่ม Job; เมื่อกด START จะลองอ่าน Variables และจะบันทึกข้อผิดพลาดใน log โดยไม่ส่งออก Job นั้นหากยังไม่มี DATE ที่ใช้ได้

ชื่อ `1117-ALL-PRE-FLX-0001-01.eps` แสดง `DATE: 1117`, `SHOP: ALL`, `SKU: PRE-FLX-0001` และ `No.: PRE-FLX-0001-01`; ชื่อ `1117-ALL-FLX-0001-01.eps` มี SKU เป็น `FLX-0001` ส่วน `PRE` เป็นส่วนของ SKU ไม่แยกเป็นประเภทงาน ชื่อ `1119-SP-N017-01-S-01.eps` มี SKU เป็น `N017-01-S` และ `1120-ALL-N017-24-MIX-01.eps` มี SKU เป็น `N017-24-MIX`

หาก DATE หรือ SKU จากชื่อ EPS ใช้ไม่ได้ สคริปต์จะอ่าน Variables ชื่อ `FN`, `DATE`, `SHOP` ในแผง **Window > Variables** จาก TextFrame ที่ผูกอยู่ โดยอ่านข้อความ `contents` ปัจจุบันของเอกสาร `FN` ควรเป็นชื่อ Job เต็มตามรูปแบบตัวอย่าง (มีหรือไม่มี `.eps` ก็ได้) เพื่อกู้รหัส SKU; `DATE` ต้องเป็น `MMDD` หรือ `MMDD(A)` และเป็นวันที่จริงในปีปัจจุบัน ส่วน `SHOP` ใช้แสดงและบันทึกใน log เท่านั้น ถ้าชื่อ EPS ถูกต้องอยู่แล้วจะใช้ชื่อ EPS ตามเดิม ไม่อ่าน Variables เป็นค่าแทน เมื่อใช้ทางสำรอง `JOB INFO` ใน log จะระบุแหล่งของค่าที่ใช้ หากยังไม่มี DATE/SKU ที่ใช้ได้ Job นั้นจะไม่ส่งออก; Variable ชื่อซ้ำหรือ TextFrame ที่ผูกหลายตัวแต่มีข้อความต่างกันถือเป็นข้อมูลกำกวมและหยุด Job นั้น

1. เลือก **File > Scripts > Other Script…** ใน Illustrator แล้วเปิด `GC-AutoCapture.js`
2. เลือก **Single Mode** เพื่อส่งออกเอกสารที่ active ไม่ว่าจะมีนามสกุลใด หรือเลือก **Batch** เพื่อประมวลผลไฟล์ EPS หลายไฟล์ ชื่อเอกสารหรือ Variables ยังต้องให้ DATE และ SKU ที่ใช้ได้
3. สำหรับ Batch กด **Browse...** ในส่วน **Folder ต้นทาง** แล้วเลือก Folder สคริปต์จะแสดงจำนวนไฟล์ `.eps` ที่พบใต้ Folder และ Subfolder ทั้งหมด พร้อมรายชื่อที่เยื้องตามระดับ Folder/Subfolder ในช่องข้อความที่เลื่อนดูได้ ลากเมาส์ครอบชื่อไฟล์ในช่องนี้แล้วกด `Ctrl+C` เพื่อคัดลอกได้ทันที ค่าเริ่มต้น **Select all** จะเลือกทุกไฟล์และทำให้ panel Optional ทั้งหมดเป็นสีเทา หากต้องการทำเฉพาะบางไฟล์ ให้เลือก **Select some...** ใน panel Folder ต้นทาง แล้วใส่ชื่อใน **START EPS** และ/หรือ **END EPS** (ใส่หรือไม่ใส่ `.eps` ก็ได้) ช่วงนี้รวมทั้งไฟล์ต้นและท้ายตามลำดับ path ที่เรียงไว้ เว้นช่องใดว่างจะเริ่มจากไฟล์แรกหรือจบที่ไฟล์สุดท้าย หากกลับไปเลือก **Select all** จะทำทุกไฟล์แม้ช่องยังมีค่าค้างอยู่ ช่องจำนวนจะแสดงจำนวนไฟล์ในช่วงที่เลือก และ `[x]` ในรายการระบุไฟล์ที่จะทำ ส่วน `[ ]` ระบุไฟล์นอกช่วง หากชื่อขอบเขตไม่พบ ซ้ำกันในหลาย Subfolder หรือ START อยู่หลัง END จะต้องแก้ชื่อก่อนเริ่มงาน
   รายการเยื้องชื่อ Folder/Subfolder ตามระดับ และใช้เส้นกิ่ง `├─` / `└─` เฉพาะบรรทัด EPS ใต้ Folder เดียวกัน โดยยังลากเมาส์เลือกข้อความได้
4. ทุกโหมดต้องเลือก **Folder ปลายทาง (Output และ Log)** ที่มีอยู่จริงก่อนกด **เริ่มส่งออก** `CONFIG.outputFolderName` กำหนดโฟลเดอร์หลักสำหรับผลลัพธ์ (หากเป็นค่าว่างจะใช้โฟลเดอร์ที่เลือกโดยตรง) โดยเก็บ log หนึ่งไฟล์ต่อรอบใน `logs/sessions` ใต้โฟลเดอร์หลัก และเก็บภาพใน `<YYYYMMDD>/<OID>/` ใต้โฟลเดอร์หลัก หากโฟลเดอร์ปลายทางที่เลือกมีชื่อ `YYYYMMDD` ตรงกับ DATE ของ Job อยู่แล้ว จะใช้โฟลเดอร์นั้นตรง ๆ และสร้างเพียง `<OID>` ภายใน เช่น เลือก `C:\Output\20261118` แล้วส่งออก Job วันที่ `1118` ในปี 2026 จะได้ `C:\Output\20261118\<OID>\` ไม่สร้าง `20261118` ซ้อน หากโฟลเดอร์วันที่หรือ OID ที่ต้องใช้ยังไม่มีจึงสร้างเพิ่ม
5. ใน Batch สคริปต์เปิด EPS ทีละไฟล์ ส่งออกและคืนสถานะ แล้วปิดไฟล์ที่สคริปต์เปิดเองโดยไม่บันทึกก่อนทำไฟล์ถัดไป หากไฟล์นั้นเปิดอยู่แล้วจะใช้เอกสารเดิมและไม่ปิดให้
6. เมื่อจบรอบ จะแสดงจำนวน Job, JPG, รายการที่ข้าม และตำแหน่ง `logs/sessions/AutoCapture_Log_*.log` จากนั้นปรับ Folder หรือช่วงไฟล์แล้วกด **START** อีกครั้งได้ โดย log ของรอบใหม่ใช้ชื่อจากเวลาเริ่มรอบ

สคริปต์ตรวจจำนวน EPS และช่วงไฟล์ในหน้าต่างก่อนเริ่มงาน โดยไม่สร้าง log หากชื่อขอบเขตไม่ถูกต้อง หลังยืนยัน Destination จะสร้าง log เดียวก่อนตรวจข้อมูลหรือเปิด EPS เพื่อบันทึกกรณีไม่พบไฟล์ การเปิด EPS การตรวจข้อมูล การส่งออก การคืนสถานะ และการปิดเอกสารก่อนแสดง Error Alert หากยังไม่ได้เลือก Destination หรือเลือก path ไม่ถูกต้อง ScriptUI จะแสดงข้อความในหน้าต่างแทน Alert เพราะยังไม่มีตำแหน่งที่เขียน log ได้

Batch จะทำไฟล์ถัดไปต่อเมื่อ Job หนึ่งผิดพลาด และสรุปข้อผิดพลาดทั้งหมดเมื่อจบรอบ หากไม่พบ EPS ใต้ Folder ที่เลือกจะบันทึกเหตุผลใน log แล้วแสดง Error Alert ส่งต่อ `GC-AutoCapture.js` ไฟล์เดียวได้ เมื่อชื่อ JPG ซ้ำกับไฟล์ที่มีอยู่ การส่งออกจะเขียนทับไฟล์เดิม

DATE ใช้ `MMDD` สี่หลักจากต้นชื่อ EPS หรือทางสำรอง Variable `DATE` โดยไม่รวมรหัสกะในวงเล็บ และต้องเป็นวันที่จริงของปีปัจจุบันของเครื่อง (รวมกฎปีอธิกสุรทิน) ชื่อโฟลเดอร์วันที่เป็น `YYYYMMDD` โดยใช้ปีปัจจุบันของเครื่อง เช่น `1102(M)` ในปี 2026 ไปที่ `20261102` หากไม่พบ DATE ที่ใช้ได้ทั้งจากชื่อ EPS และ Variables Job นั้นไม่ส่งออกภาพและบันทึกข้อผิดพลาดใน log; Batch จะทำไฟล์ถัดไปต่อ

กรณีตรวจทางสำรองใน Illustrator: ใช้สำเนา EPS ที่ชื่อขาด DATE แต่ Variable `DATE` มีค่าถูกต้อง; ชื่อขาด SKU แต่ `FN` เป็นชื่อ Job ที่ถูกต้อง; Variable `DATE` เป็นวันที่ไม่จริง; Variable `FN` ไม่มี SKU; และ TextFrame ที่ผูก Variable ชื่อเดียวกันมีค่าขัดกัน ตรวจค่าหน้า Status, `JOB INFO`/`ERROR` ใน log, ชื่อ JPG และโฟลเดอร์วันที่ด้วยปลายทางทดสอบแยก

## เริ่มใช้งานผ่าน Illustrator (เอกสารที่เปิดอยู่)

ระหว่างส่งออก JPG สคริปต์ซ่อน Layer และ Group ทุกระดับที่ชื่อมีคำว่า `Frame` (ไม่แยกตัวพิมพ์เล็ก/ใหญ่) พร้อมกรอบที่เลือกและ Layer `Border` ตามกฎเดิม แล้วคืนค่า visibility ของแต่ละรายการหลังส่งออกหรือเมื่อเกิดข้อผิดพลาด

1. เปิดเอกสารใน Illustrator และเตรียม Layer หรือ Group ชื่อตรงกับ `CONFIG.frameLayerNames`: `CutLine`, `Cut-Line`, `กรอบ`, `Layout` หรือ `FrameLine` โดยไม่แยกตัวพิมพ์เล็ก–ใหญ่และตัดช่องว่างหัวท้ายก่อนเทียบ
2. วาง Rectangle ที่สูงกว่า 0.5 cm ไว้ภายใน container นี้ รวม Group ซ้อนหรือ sublayer ได้
3. ตั้งชื่อเอกสารตาม job เช่น `1028(M)-TT-N012-03-01.eps` และเตรียม Layer `Name` หรือ `NAME` กับ `OID` ตามรายละเอียดด้านล่าง
4. เลือก **File > Scripts > Other Script…** แล้วเปิด `GC-AutoCapture.js`
5. เลือก **Single Mode**, เลือก Folder ปลายทาง แล้วกด **START** จะได้ไฟล์ เช่น `20261028/12345678901234567890/1028(M)-N012-03-01-12345678901234567890-003.jpg` พร้อม log หนึ่งไฟล์สำหรับรอบนั้น

ชื่อไฟล์ปัจจุบันคือ **GC-AutoCapture.js** ตามไฟล์ในโปรเจกต์ โปรดใช้ชื่อนี้ในการเปิดสคริปต์

ปัจจุบันใช้ไฟล์นามสกุล **`.js`** สำหรับพัฒนาและส่งมอบ สามารถเลือกไฟล์นี้ผ่านเมนูข้างต้นได้โดยใช้ชื่อเดิม สคริปต์ยังทำงานด้วย Adobe Illustrator ExtendScript และใช้ไวยากรณ์ JavaScript แบบ ES3

## อัปเดตสคริปต์ใน Illustrator จาก NAS

ใช้ [updater/Update-Illustrator-Script.bat](updater/Update-Illustrator-Script.bat) บนเครื่อง Windows แต่ละเครื่องเพื่อคัดลอก `G:\004 Program\illustrator-Stuff\Auto Capture\GC-AutoCaputre.js` ไปยัง `%ProgramFiles%\Adobe\Adobe Illustrator 20xx\Presets\en_US\Scripts\GC-AutoCaputre.js` โดยอัตโนมัติ หากติดตั้ง Illustrator หลายปี สคริปต์จะอัปเดตทุกปีที่พบ และเขียนทับไฟล์ชื่อเดิม

1. ปิด Illustrator แล้วตรวจว่าเครื่องมองเห็นไฟล์ต้นทางบนไดรฟ์ `G:`
2. เปิด **Command Prompt แบบ Run as administrator** และเรียกไฟล์ `.bat` นี้จากตำแหน่งที่เก็บไว้ หรือคลิกขวาไฟล์แล้วเลือก **Run as administrator**
3. อ่านผล `[OK]`, `[SKIP]` หรือ `[ERROR]` ของแต่ละเวอร์ชันในหน้าต่าง ก่อนกดปุ่มใด ๆ เพื่อปิดหน้าต่าง แล้วเปิด Illustrator ใหม่เพื่อให้เมนู **File > Scripts** โหลดไฟล์ที่อัปเดต

หากเปิดแบบ Administrator แล้วไม่เห็นไดรฟ์ `G:` ให้เชื่อมต่อ NAS ใน Command Prompt ที่ยกระดับสิทธิ์นั้น หรือเปลี่ยนค่า `SOURCE` ตอนต้นของ `.bat` เป็น UNC path ของ NAS ที่เข้าถึงได้ สคริปต์จะข้ามเวอร์ชันที่ไม่มี `Presets\en_US` และแจ้งว่าล้มเหลว; เครื่องที่ใช้ภาษา Presets อื่นต้องปรับ path ใน `.bat` ให้ตรงก่อนใช้งาน การคัดลอกต้องมีสิทธิ์เขียนใน `Program Files`

เมื่ออัปเดตไม่สำเร็จ หน้าต่างจะแยกกรณีไดรฟ์ `G:` ใช้ไม่ได้, ไม่พบโฟลเดอร์หรือไฟล์ต้นทาง, ไม่พบโฟลเดอร์ Adobe/Illustrator หรือ `en_US` และแสดงข้อความผิดพลาดของ Windows ก่อนบรรทัด `[ERROR]` เมื่อสร้างโฟลเดอร์หรือคัดลอกไม่ได้ ผลรวมท้ายหน้าต่างระบุจำนวนที่อัปเดตสำเร็จและจำนวนที่ข้ามหรือล้มเหลว

## ชื่อไฟล์และการจับคู่ Order ID

รูปแบบส่งออกคือ `<YYYYMMDD>/<OID>/[DATE]-[รหัสจากชื่อเอกสาร]-[Order ID]-ลำดับกรอบ.jpg` เช่น `20261102/123456/1102(M)-L007-N02-01-123456-001.jpg` โดย DATE ในชื่อภาพใช้ค่าจากต้นชื่อ EPS ตามที่แสดงใน Status (รวมรหัสในวงเล็บ) ส่วนรหัสจากชื่อเอกสารมี 4 แบบ: `SKU-รหัสรูปแบบ-ลำดับที่`, `SKU-รหัสรูปแบบ`, `SKU-ลำดับที่` หรือ `SKU`

เมื่อกรอบที่ส่งออกสำเร็จมี **เลขกรอบต่อเนื่องกันและ OID เดียวกัน** อย่างน้อย 2 กรอบ สคริปต์จะสร้างภาพรวม PNG24 โดยวาง JPG แยกตามลำดับกรอบจากซ้ายไปขวาแบบชิดกัน จัดขอบบนให้ตรงกัน และใช้พื้นหลังสีขาวหากความสูงต่างกัน ภาพรวมใช้สเกลตาม `CONFIG.targetDPI` เดียวกับ JPG; PNG ไม่บีบอัดแบบสูญเสียเพิ่ม แต่รายละเอียดที่หายไปจาก JPG แยกจะไม่กลับมา กรอบที่ข้ามหรือ `EmptyOID` จะไม่ถูกรวม หลังสร้าง PNG สำเร็จจึงย้าย JPG ของกลุ่มนั้นไปยัง `<YYYYMMDD>/<OID>/Individual Image/` หาก PNG หรือการย้ายล้มเหลว สคริปต์หยุด Job พร้อมบันทึกข้อผิดพลาด และเก็บ JPG ที่ยังไม่ได้ย้ายไว้

ภาพรวมกลุ่มเดียวใช้ชื่อ `[DATE]-[รหัสจากชื่อเอกสาร]-[OID]-Mixed.png` เช่น `1102(M)-N012-10-01-123456-Mixed.png` หาก OID เดียวกันมีหลายกลุ่มที่เลขกรอบไม่ต่อเนื่องกัน ให้แยกเป็น `Mixed-01.png`, `Mixed-02.png` ตามลำดับกรอบ เช่น 005–006 และ 010–011 ภาพรวมและ `Individual Image` อยู่ใต้ `<โฟลเดอร์ปลายทาง>/<YYYYMMDD>/<OID>/`

- **SKU และลำดับที่**: เก็บรหัสทุกส่วนก่อนเลขลำดับ 2 หลักท้ายชื่อเป็น SKU เต็ม เช่น `N003-A`, `N012-11`, `N017-01-S`, `N017-24-MIX`, `FLX-0001` และ `PRE-FLX-0001` ชื่อ `N003-01` มี SKU `N003` กับลำดับ `01` ส่วน `N017-01-S-01` มี SKU `N017-01-S` กับลำดับ `01` รหัส `S`, `M`, `L` และ `MIX` ใช้หลังเลข 2 หลักของ `N017`; `PRE` เป็นส่วนหนึ่งของ SKU และอยู่ในชื่อ JPG ด้วย
- **ลำดับกรอบ**: คัด Rectangle ที่สูงไม่เกิน 0.5 cm ออกก่อน แล้วเรียงกรอบที่เหลือตาม Y ของขอบบนจากบนลงล่าง หาก Y เท่ากันจะเรียงตาม X ของขอบซ้ายจากซ้ายไปขวา จึงได้ลำดับแบบอ่านทีละแถวจากบนซ้ายไปขวาแล้วลงแถวถัดไป หาก X และ Y เท่ากันจะใช้ลำดับวัตถุเดิม พิกัด X/Y เป็นหน่วย points จาก `geometricBounds` ของ Illustrator นับจาก 1 ก่อนคัดกรอบที่ข้าม กรอบที่ถูกคัดออกไม่กินลำดับ เช่น 3 Rectangle ที่มี 2 อันสูงไม่เกิน 0.5 cm จะนับเป็น 1 กรอบ ใช้ลำดับกรอบเป็นเลขท้ายชื่อ JPG โดยเติมศูนย์ตาม `fileNumberDigits` เช่น กรอบที่ 3 ได้ `003` ไม่อ่านหรือตรวจตัวเลขหลัง `N` ในชื่อวัตถุ
- **Layer `Name` หรือ `NAME`**: แต่ละกรอบต้องมี `TextFrame` (Type) หรือ Group ที่ตั้งชื่อไว้ อย่างน้อยหนึ่งรายการใน Layer ที่เลือก รวมระดับซ้อนกัน ชื่อ Type เป็นค่าใดก็ได้ ส่วน Group ต้องมีชื่อที่ไม่ว่าง ใช้จุดกึ่งกลาง `geometricBounds` ของวัตถุนั้นตรวจว่าอยู่ในกรอบใด โดยขอบร่วมเป็นของกรอบทางขวาหรือด้านล่าง หากชื่อวัตถุ Type ลงท้ายด้วย `-BC` หรือ `_BC` (รวมตัวพิมพ์เล็ก เช่น `-bc`, `_bc`) อักขระทุกตัวใน Type นั้นต้องใช้ฟอนต์ `Libre Barcode 128 Text` สไตล์ `Regular` จึงจะส่งออกกรอบนั้น
- **Order ID**: ค้นวัตถุ Type ภายใน Layer หรือ Group ชื่อ `OID` รวม Group ซ้อนกัน แล้วใช้จุดกึ่งกลาง `geometricBounds` ตรวจว่า OID อยู่ในกรอบส่งออกใด ไม่ใช้ลำดับซ้อนใน Layers panel อ่านค่าจาก **Name ของวัตถุ** ก่อน หาก Name ว่างจะอ่าน `contents` รองรับเลขล้วนหรืออักษรอังกฤษผสมตัวเลข เช่น `123456`, `ABC123` และ `123ABC` โดยเก็บเป็นข้อความเพื่อรักษาศูนย์นำหน้าและเลขออเดอร์ยาว
- **เมื่อไม่มี Layer/Group `OID`**: ตรวจ Group ชื่อ `N` ตามด้วยตัวเลขใน Layer `Name`/`NAME` ที่เลือก เช่น `N3` โดย Group และ Type ต้องมีจุดกึ่งกลางอยู่ในกรอบเดียวกัน ใช้ `contents` ของ Type ชื่อ `N3-OID` หรือ `N3_OID` เป็น OID ก่อน หากไม่มี Type ชื่อแบบนี้ในกรอบ จึงใช้ Name หรือ contents ของ Type ใน Group ที่เป็นตัวเลขล้วนหรืออักษรอังกฤษผสมตัวเลขยาว 14–18 ตัว เช่น `12345678901234` หรือ `AB123456789012` ถ้าพบหลาย Type ในแบบที่เลือก หรือค่า OID ว่าง/ไม่ถูกต้อง จะข้ามกรอบพร้อมเหตุผลใน log การมี Layer/Group `OID` จะยังใช้การจับคู่จากที่นั้นตามเดิม
- **การจับคู่**: แต่ละกรอบต้องพบ Type หรือ Group ที่ตั้งชื่อไว้ใน `Name` หรือ `NAME` อย่างน้อยหนึ่งรายการและ OID ที่มีค่าเพียงหนึ่งรายการในพื้นที่เดียวกัน หากมี TextFrame ของ OID ที่ทั้ง Name และ contents ว่างอยู่ด้วย จะมองข้ามตัวว่างและใช้ OID ที่มีค่า เลขท้ายชื่อไฟล์ใช้ลำดับกรอบเดิม เช่น กรอบที่ 3 ได้ `003` แม้กรอบก่อนหน้าถูกข้าม และเลขตั้งแต่ 1000 ขึ้นไปไม่ถูกตัด
- **เวลาส่งออก**: บันทึกใน log แทนชื่อ JPG ใช้เวลาท้องถิ่นของเครื่อง โดยอ่านเวลาที่ส่งออกแต่ละภาพเสร็จใหม่หลัง `exportFile` สำเร็จ; DATE ในชื่อภาพมาจากชื่อ EPS

หากมี TextFrame ของ OID ว่างเพียงอันเดียวในกรอบ หรือ OID ที่เลือกมีค่าแต่ไม่ใช่เลขล้วน/อักษรอังกฤษผสมตัวเลข สคริปต์จะยังส่งออกภาพและใช้ `EmptyOID` แทน Order ID ในชื่อไฟล์ เช่น `1102(M)-N012-11-01-EmptyOID-002.jpg` หากไม่มี Layer ที่ต้องใช้ ไม่มี Type หรือ Group ที่ตั้งชื่อไว้ใน `Name` หรือ OID ในพื้นที่นั้น มี OID ที่มีค่าหลายรายการ มี TextFrame ว่างหลายรายการโดยไม่มี OID ที่มีค่า marker ใน `Name`/OID ที่เลือกอยู่ในหลายกรอบที่ซ้อนกัน หรือ Type marker ชื่อลงท้าย `-BC`/`_BC` ใช้ฟอนต์ไม่ตรงหรือไม่มีอักขระให้ตรวจ จะข้ามกรอบพร้อมเหตุผลใน log แม้มี marker อื่นในกรอบเดียวกัน หากข้ามทั้งหมดจะยังเก็บ log ที่ปลายทางโดยไม่แก้ Artboard หรือ visibility เมื่อจบคิวจะแสดงจำนวนภาพที่ส่งออกและข้ามพร้อมตำแหน่ง log

ใช้ชื่อ Layer `Name` หรือ `NAME` สำหรับ marker และ `OID` สำหรับ Order ID ตรงตามตัวพิมพ์ โดยค้น sublayer ได้ หากมีทั้ง `Name` และ `NAME` จะใช้ Layer แรกที่พบ สามารถเก็บ Type และ Group ที่ตั้งชื่อไว้ใน Group ซ้อนกันได้ ส่วน OID ยังต้องเป็น TextFrame และต้องวางจุดกึ่งกลางภายในกรอบที่ต้องการจับคู่

## บันทึกการส่งออก

หลังคลิก **เริ่มส่งออก** จะสร้างไฟล์ UTF-8 เพียงหนึ่งไฟล์ต่อรอบชื่อ `AutoCapture_Log_YYYYMMDD_HHMMSS.log` ใน `logs/sessions` ใต้โฟลเดอร์หลักของผลลัพธ์ โดยสร้างโฟลเดอร์นี้เมื่อเริ่มรอบ ส่วน JPG จะอยู่ในโฟลเดอร์ย่อยตาม DATE แล้วจึงตาม OID โดยเวลาในชื่อ log คือเวลาเริ่มรอบ หากชื่อ log ซ้ำจะเติม `_02`, `_03` ต่อไปเพื่อรักษา log เดิม การเลือกปลายทางอย่างเดียวยังไม่สร้าง log หรือโฟลเดอร์ log หากสร้างโฟลเดอร์หรือเขียน log ไม่สำเร็จจะหยุดและแจ้งข้อผิดพลาด

- `RUN START` และ `DISCOVERED`: โหมดการทำงาน, ปลายทาง จำนวน EPS ทั้งหมดและจำนวนที่เลือกในโหมด Batch พร้อมชื่อ START EPS / END EPS
- `JOB START` และ `JOB INFO`: พาธต้นฉบับ, SKU เต็ม, ลำดับ (ถ้ามี), DPI, คุณภาพ JPG และจำนวนกรอบ/รายการที่เตรียมส่งออก/รายการที่ข้าม เช่น `L007-N02-01` แสดง `SKU: L007-N02 | 01`, `N003-A` แสดง `SKU: N003-A`, `N003-01` แสดง `SKU: N003 | 01` และ `PRE-FLX-0001-01` แสดง `SKU: PRE-FLX-0001 | 01`
- `BEFORE` และ `AFTER`: ลำดับ Job, ขั้นตอน `OPEN_EPS`, `PARSE_FILENAME`, `SCAN_FRAMES`, `VALIDATE_JOB`, `MATCH_FRAMES`, `SNAPSHOT_DOCUMENT`, `SETUP_EXPORT`, `PREPARE_OUTPUT`, `EXPORT_JPG`, `RESTORE_DOCUMENT` หรือ `CLOSE_EPS` และเวลาที่ใช้เป็นมิลลิวินาที หากงานหยุดกะทันหัน ให้ดู `BEFORE` สุดท้ายที่ไม่มี `AFTER`
- `MATCH`: กรอบ, ชื่อและจำนวน Name marker, OID ที่เลือกและจำนวน OID ในกรอบ, ผล `READY`/`SKIPPED` และเหตุผลเมื่อข้าม; `OIDCount=-` หมายถึงข้ามก่อนตรวจ OID
- `EXPORTED`: วันเวลาที่ส่งออกภาพนั้นเสร็จ, ลำดับกรอบ (`Frame` และ `Work`), OID, ชื่อไฟล์, X/Y ของขอบซ้ายบนและขอบเขตภาพ (`Bounds`)
- `MIXED` และ `MOVED`: path ของ PNG รวม ช่วงกรอบ และ path ใหม่ของ JPG แยกหลังย้ายสำเร็จ; จำนวน JPG ในผลรวมยังนับเฉพาะภาพแยก
- `SKIPPED`: ลำดับกรอบ, X/Y ของขอบซ้ายบน, ขอบเขตภาพและเหตุผลที่ข้าม เช่น ไม่มี Type ใน `Name` ไม่มี OID หรือข้อมูลกำกวม
- `JOB END`: สถานะและจำนวนภาพที่ส่งออก ข้าม และยังไม่ได้ส่งออกของ Job นั้น
- `ERROR`, `RUN END` และ `ALERT ERROR`: ข้อผิดพลาดพร้อม Job/Step/Source เมื่อเป็นข้อผิดพลาดราย Job รวมปัญหาการคืนสถานะ และผลรวมทั้งรอบ

แต่ละเหตุการณ์อยู่หนึ่งบรรทัดพร้อมเวลาท้องถิ่นละเอียดถึงมิลลิวินาที; มีบรรทัดว่างสองบรรทัดก่อน `JOB START` ของ Job ถัดไปเพื่อแยกแต่ละ Job ข้อความ error ที่มีหลายบรรทัดจะแสดง `\n` ในบรรทัดเดียว เขียนและปิด log หลังแต่ละรายการเพื่อเก็บผลก่อนหน้าไว้เมื่อภาพถัดไปส่งออกผิดพลาด หากสร้างหรือเขียน log ไม่สำเร็จจะหยุดและแจ้งข้อผิดพลาด การยกเลิกเลือกปลายทางไม่สร้าง log ชื่อ JPG ไม่มีเวลาแล้ว และเมื่อชื่อซ้ำจะเขียนทับ JPG เดิม

## พฤติกรรมที่ต้องทราบ

- ค้นหา Layer หรือ Group รวมระดับซ้อนที่ชื่อตรงกับ `frameLayerNames` และใช้ container แรกที่พบเพียงแห่งเดียว ไม่รวมกรอบจากหลาย container
- เทียบชื่อกรอบทั้งชื่อในเอกสารและใน CONFIG โดยตัดช่องว่างหัวท้ายและไม่แยกตัวพิมพ์เล็ก–ใหญ่ เช่น `CutLine`, `CUTLINE` และ ` cutline ` ตรงกัน แต่ `CutLine Backup` ไม่ตรง ช่องว่างภายในชื่อและเครื่องหมายขีดยังคงมีผล กฎนี้ใช้เฉพาะชื่อ container กรอบ ส่วน Layer marker รับเฉพาะ `Name` หรือ `NAME` และ `OID` กับ `Border` ใช้กฎเดิม
- ใช้ `PathItem` ที่เป็นเส้นปิด 4 จุดและสูงกว่า `minFrameHeightCm` (ค่าเริ่มต้น 0.5 cm) เป็น Rectangle กรอบ โดยไล่ค้น Group และ sublayer ภายใน container ที่เลือก แต่ไม่ไล่ภายใน Compound Path; สคริปต์แปลง cm เป็น points ก่อนเทียบกับ `height` ของ Illustrator API
- ใช้เฉพาะกรอบที่พบจริงในเอกสาร ทุก SKU รวมถึง `N012` ต้องมีกรอบครบตามพื้นที่ที่ต้องการส่งออก ไม่มีการเติมพิกัดกรอบทางขวาอัตโนมัติ
- เรียงกรอบจากซ้ายไปขวาตามค่า left ของ `geometricBounds` หาก left เท่ากันจะคงลำดับจาก collection เดิม ไม่ได้เรียงเป็นแถวบนลงล่าง
- ซ่อน Layer หรือ Group กรอบที่เลือกทั้ง container ระหว่างส่งออก จึงไม่ควรเก็บงานภาพที่ต้องการส่งออกไว้ใน container เดียวกัน
- ซ่อน Layer ชื่อ `Border` ทุกตัว รวม sublayer ระหว่างส่งออก และคืน visibility เดิมของแต่ละ Layer หลังจบงานหรือเกิดข้อผิดพลาด หากไม่มี `Border` จะส่งออกตามปกติ
- ใช้ Artboard แรกเป็นพื้นที่ส่งออกชั่วคราว และเลือก Artboard นี้ให้ active ระหว่างส่งออก
- คืนขอบเขต Artboard, การแสดง Layer และ Artboard ที่ active เดิม ทั้งเมื่อสำเร็จและเมื่อส่งออกผิดพลาด หากคืนค่าใดไม่สำเร็จจะยังพยายามคืนค่าอื่นและแจ้งข้อผิดพลาด
- หากยกเลิกการเลือกโฟลเดอร์ จะไม่แก้สถานะเอกสารหรือส่งออกไฟล์
- เอกสารที่ยังไม่บันทึกใช้โฟลเดอร์ Documents เป็นจุดเริ่มต้นของหน้าต่างเลือกปลายทาง
- เลือกปลายทางใน UI ก่อนเริ่มคิว และตรวจข้อมูลการตั้งชื่อก่อนแก้ Artboard หรือ visibility
- หากส่งออกบางไฟล์แล้วเกิดข้อผิดพลาด ไฟล์ที่ส่งออกสำเร็จก่อนหน้ายังอยู่ หากชื่อซ้ำกับ JPG เดิมจะเขียนทับไฟล์นั้น
- สคริปต์ไม่บันทึกต้นฉบับอัตโนมัติ EPS ที่สคริปต์เปิดจากคิวจะถูกปิดแบบไม่บันทึกหลัง Job ส่วนเอกสารที่เปิดอยู่ก่อนแล้วจะคงเปิดไว้ การเปลี่ยน Artboard ชั่วคราวอาจทำให้เอกสารที่คงเปิดอยู่แสดงว่าถูกแก้ไข แม้จะคืนขอบเขตเดิมแล้ว

## จุดตั้งค่าสำหรับนักพัฒนา

แก้ `CONFIG` ที่ต้นไฟล์ โดยไม่ต้องแก้ลูปส่งออก:

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `uiTitle` / `uiVersion` | `AutoCapture` / `1.0.3` | ชื่อและเวอร์ชันบนแถบชื่อ ScriptUI; สคริปต์เติม ` v` ระหว่างสองค่านี้ให้อัตโนมัติ |
| `frameLayerNames` | `["CutLine", "Cut-Line", "กรอบ", "Layout", "FrameLine"]` | ชื่อ Layer หรือ Group ที่ยอมรับ รวมระดับซ้อน เทียบชื่อเต็มโดยไม่แยกตัวพิมพ์เล็ก/ใหญ่และตัดช่องว่างหัวท้าย |
| `targetDPI` | `96` | ความละเอียดภาพ คำนวณ scale เป็น `(DPI / 72) * 100` |
| `jpegQuality` | `100` | คุณภาพ JPG ช่วง 0–100 |
| `minFrameHeightCm` | `0.5` | ความสูงขั้นต่ำของกรอบ หน่วย cm; ต้องสูงกว่าเกณฑ์นี้จึงถูกนับ |
| `fileNumberDigits` | `3` | จำนวนหลักขั้นต่ำของลำดับกรอบ เช่น `012` |
| `exportArtboardIndex` | `0` | Artboard ที่ใช้ส่งออก เริ่มนับจาก 0 และต้องมีอยู่ในเอกสาร |
| `outputFolderName` | `""` ใน working copy | ชื่อโฟลเดอร์หลักของผลลัพธ์; ค่าว่างใช้ปลายทางที่เลือกโดยตรง ส่วน `.AutoCapture` จะใช้โฟลเดอร์ชื่อนั้นหรือสร้างภายในปลายทางที่เลือก |
| `barcodeFontFamily` / `barcodeFontStyle` | `Libre Barcode 128 Text` / `Regular` | ฟอนต์ที่ Type marker ชื่อลงท้าย `-BC` หรือ `_BC` ต้องใช้ทุกอักขระ |
| `uiWidth` | `520` | ความกว้างของช่อง path ใน ScriptUI |

ค่าปัจจุบันใช้ **96 DPI** ตามการตั้งค่าในสคริปต์ หากต้องการ 300 ให้แก้ `targetDPI` เป็น `300` ควรใช้จำนวนบวกสำหรับ DPI และจำนวนหลัก และตรวจข้อจำกัดขนาดภาพ/scale กับ Illustrator รุ่นที่ใช้งาน

## โครงสร้างและแนวทางแก้ไข

คงสคริปต์เป็นไฟล์เดียวเพื่อให้ส่งต่อและรันผ่าน Illustrator ได้โดยไม่ต้องติดตั้ง package หรือ build ส่วน helper อยู่ภายใน closure เพื่อไม่เพิ่มชื่อใน global scope

`showCaptureDialog()` สร้าง ScriptUI ในไฟล์เดียวกับกฎส่งออก `runSelection()` สร้าง log เดียวก่อนเริ่มงาน และ `executeJob()` ตรวจและส่งออกเอกสารทีละไฟล์

| ส่วน | หน้าที่ / เมื่อใดควรแก้ |
| --- | --- |
| `showCaptureDialog()` / `getEpsTreeText()` | หน้าต่างเลือกโหมด, Folder ต้นทางสำหรับ Batch, รายชื่อ EPS ที่เลือกข้อความได้ และ Folder ปลายทาง |
| `executeJob()` | ตรวจเอกสาร เตรียมรายการส่งออก และเขียนรายละเอียด Job ลง log กลาง |
| `findFrameContainer()` | กฎการเลือก Layer หรือ Group ตาม `frameLayerNames` |
| `collectFrames()` / `copyBounds()` | เลือก Rectangle ที่สูงกว่า `minFrameHeightCm` รวม Group ซ้อน ถ่ายสำเนาพิกัด และเรียงลำดับก่อนแก้เอกสาร |
| `getSku()` | ตรวจท้ายชื่อ job เป็น SKU ตัวอังกฤษ 1 ตัวและเลข 3 หลักพร้อม suffix เดิม หรือ `FLX-เลข 4 หลัก-ลำดับ 2 หลัก` |
| `prepareExports()` / `collectNameMarkers()` / `collectTextFrames()` | ตรวจ Type หรือ Group ที่ตั้งชื่อไว้ใน `Name` หรือ `NAME` และ Type ใน `OID` ตามตำแหน่ง ใช้ลำดับกรอบเป็นเลขท้ายไฟล์ แล้วข้ามกรอบที่ข้อมูลไม่ครบหรือกำกวม |
| `getDefaultFolder()` | โฟลเดอร์เริ่มต้น รวมกรณีเอกสารยังไม่บันทึก |
| `ensureOutputFolder()` | ตรวจชื่อ Folder ปลายทาง และสร้าง Folder ลูกตาม `outputFolderName` เมื่อชื่อไม่ตรง |
| `createExportOptions()` | ตัวเลือก JPG และ scale |
| `createOutputFile()` | ใช้ DATE ตามด้วยรหัสจากชื่อเอกสาร Order ID และลำดับกรอบ โดยส่งออกซ้ำที่ path เดิม |
| `createLog()` / `appendLog()` | สร้าง log หนึ่งไฟล์ต่อรอบและบันทึกวันเวลาส่งออกแต่ละภาพ รายการที่ข้าม ข้อผิดพลาดและสรุปผล |
| `exportFrames()` | เก็บสถานะ ส่งออก และเรียกคืนสถานะใน `finally` |
| `restoreDocumentState()` | พยายามคืนทุกสถานะและรวบรวมข้อผิดพลาด |

ข้อกำหนดในการพัฒนาต่อ:

- บันทึกไฟล์เป็น UTF-8 เพื่อรักษาชื่อ Layer และข้อความภาษาไทย
- ใช้ JavaScript แบบ ES3 สำหรับ ExtendScript: `var`, function ปกติ และลูปพื้นฐาน หลีกเลี่ยง `let`, `const`, arrow function, module import และ API จาก Node/browser
- เก็บ `#target illustrator` และคำสั่งเรียกทำงานท้ายไฟล์ไว้
- หากเพิ่มการเปลี่ยนสถานะเอกสาร ต้องเก็บค่าก่อนเปลี่ยนและเพิ่มการคืนค่าใน `restoreDocumentState()` พร้อมทดสอบกรณีผิดพลาด
