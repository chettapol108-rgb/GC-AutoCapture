# GC-AutoCapture

Change history / ประวัติการเปลี่ยนแปลง: [CHANGELOG.md](CHANGELOG.md)

สคริปต์ Adobe Illustrator สำหรับส่งออก JPG ตามขอบเขต Rectangle ที่มี `height > 1` pt ใน Layer หรือ Group ตามรายชื่อ `CONFIG.frameLayerNames` จากเอกสารที่เปิดอยู่ รองรับ EPS และเอกสาร Illustrator อื่น ๆ

## ScriptUI สำหรับ EPS หลายไฟล์

1. เลือก **File > Scripts > Other Script…** ใน Illustrator แล้วเปิด `GC-AutoCaputre.js` หน้าต่างทั้งหมดอยู่ในไฟล์ `.js` เดียว ใช้ ScriptUI โดยตรง
2. เลือก **ส่งออกเอกสารที่เปิดอยู่ปัจจุบัน** เพื่อส่งออกเฉพาะเอกสารที่ active ตอนเปิด ScriptUI รวมเอกสารที่ยังไม่บันทึก หรือเลือก **ส่งออกไฟล์ EPS จากคิว** สำหรับงานหลายไฟล์
3. ในโหมดคิว กด **Browse EPS...** เพื่อเลือกหลายไฟล์, **เพิ่ม Folder...** หรือใช้ **Copy as path** แล้ววางในช่อง path หนึ่งรายการต่อบรรทัดและกด **เพิ่มจาก Path** รองรับ path ภาษาไทยและเครื่องหมายครอบ `"..."`
4. เลือก **รวมโฟลเดอร์ย่อย** ก่อนเพิ่มโฟลเดอร์หากต้องการค้น EPS ใต้โฟลเดอร์นั้นด้วย ค่าเริ่มต้นอ่านเฉพาะโฟลเดอร์ที่เลือก คิวตัด path ซ้ำและลบรายการที่เลือกได้
5. เลือกหรือวาง path ใน **Output folder** แล้วกด **เริ่มส่งออก** ในโหมดคิว Illustrator จะเปิด EPS เพียง Job เดียว ส่งออกให้เสร็จ ปิดไฟล์นั้นโดยไม่บันทึก แล้วจึงเปิด Job ถัดไป หาก EPS เปิดอยู่ก่อนแล้วจะใช้เอกสารนั้นและไม่ปิดให้
6. ดูสถานะรายไฟล์ จำนวน JPG/รายการที่ข้าม และ progress รวม ซึ่งนับ Job ที่เสร็จแล้วรวมกับสัดส่วน JPG ใน Job ปัจจุบัน รายละเอียดระหว่างส่งออกแสดงชื่อ Job, Frame, Work, OID และ path ของ JPG
7. เมื่อเสร็จ ดู JPG, log ราย Job `AutoCapture_Log_*.txt` และ log สรุปคิว `AutoCapture_Batch_*.txt` ในโฟลเดอร์ปลายทาง หน้าต่างจะแสดงผลรวมและ path ของ log

แถบรวมแสดงสัดส่วน Job ที่เสร็จแล้วรวมกับ JPG ใน Job ปัจจุบัน แถบราย Job แสดงจำนวน JPG ที่ส่งออกแล้ว รายละเอียดแสดง Job, Frame, Work, OID และ path ของไฟล์ โดยอัปเดตหน้าต่างก่อนและหลัง `exportFile` แต่ละภาพ การเปิด EPS และการส่งออกภาพเดียวเป็นงานแบบ synchronous จึงไม่มีเปอร์เซ็นต์ระหว่างที่คำสั่งนั้นยังไม่คืนค่า

**หยุดหลัง Job นี้** รอให้ Job ปัจจุบันส่งออกและคืนสถานะเสร็จ แล้วไม่เริ่มไฟล์ถัดไป การรับปุ่มเกิดได้ระหว่างจุดอัปเดต UI หากพบข้อผิดพลาด รวมถึง log เขียนไม่ได้ จะหยุดคิวและแสดงเหตุผล รายการที่ยังไม่รันแสดง `Not run` การปิดหน้าต่างก่อนกดเริ่มไม่ส่งออกหรือสร้าง log

Log สรุปคิวเป็น UTF-8 บันทึกต้นทาง ผลแต่ละ Job, path ของ log ราย Job, ข้อผิดพลาด และผลรวม โดยเก็บชื่อซ้ำด้วย suffix เดิม ทั้งสองชนิดเขียนผลระหว่างทำงานและสรุปเมื่อจบรอบ กรณีเปิด EPS ไม่สำเร็จหรือตรวจข้อมูลไม่ผ่านก่อนสร้าง log ราย Job จะมีเหตุผลใน log สรุปคิว

ส่งต่อ `GC-AutoCaputre.js` ไฟล์เดียวได้ EPS ที่สคริปต์เปิดเองจะถูกปิดแบบไม่บันทึกหลัง Job เสร็จ แม้ Job นั้นผิดพลาด ส่วนเอกสารที่เปิดอยู่ก่อนเริ่มจะไม่ถูกปิด และเมื่อจบคิวจะพยายามกลับไปเอกสารที่ active ก่อนเริ่ม ใช้โฟลเดอร์ปลายทางแยกเมื่อทดสอบ เพราะ JPG ชื่อเดิมอาจถูกเขียนทับ

## เริ่มใช้งานผ่าน Illustrator (เอกสารที่เปิดอยู่)

1. เปิดเอกสารใน Illustrator และเตรียม Layer หรือ Group ชื่อตรงกับ `CONFIG.frameLayerNames`: `CutLine`, `กรอบ`, `Layout` หรือ `FrameLine`
2. วาง Rectangle ที่มี `height > 1` pt ไว้ภายใน container นี้ รวม Group ซ้อนหรือ sublayer ได้
3. ตั้งชื่อเอกสารตาม job เช่น `1028(M)-TT-N012-03-01.eps` และเตรียม Layer `Name` กับ `OID` ตามรายละเอียดด้านล่าง
4. เลือก **File > Scripts > Other Script…** แล้วเปิด `GC-AutoCaputre.js`
5. เลือก **ส่งออกเอกสารที่เปิดอยู่ปัจจุบัน**, เลือกโฟลเดอร์ปลายทาง แล้วกด **เริ่มส่งออก** จะได้ไฟล์ เช่น `N012-03-01-12345678901234567890-003.jpg` พร้อม log ราย Job และ log สรุปคิว

ชื่อไฟล์ปัจจุบันสะกดว่า **GC-AutoCaputre.js** ตามไฟล์ในโปรเจกต์ โปรดใช้ชื่อนี้ในการติดตั้งและทดสอบ

ปัจจุบันใช้ไฟล์นามสกุล **`.js`** สำหรับพัฒนาและส่งมอบ สามารถเลือกไฟล์นี้ผ่านเมนูข้างต้นได้โดยใช้ชื่อเดิม สคริปต์ยังทำงานด้วย Adobe Illustrator ExtendScript และใช้ไวยากรณ์ JavaScript แบบ ES3

## ชื่อไฟล์และการจับคู่ Order ID

รูปแบบส่งออกคือ `[SKU พร้อมเลขชุดเดิมถ้ามี]-[Order ID]-ลำดับ.jpg`

- **SKU และเลขชุดเดิม**: ชื่อเอกสารต้องมีเดือนและวันแบบ `MMDD` กับ SKU เป็นอย่างน้อย เช่น `1028-N012.eps` หรือ `1028-N012-16.eps` ไม่บังคับช่วงเวลา `(M)`/`(N)`, Platform หรือเลขชุด เก็บส่วน SKU และเลขชุดต่อท้ายทั้งหมดตามต้นฉบับ เช่น `1028(M)-TT-N012-16-01.eps` ได้ชื่อ JPG `N012-16-01-OID-001.jpg` ส่วน `1028-N012-16.eps` ได้ `N012-16-OID-001.jpg` โดยไม่เติมเลขชุดที่ไม่มีในต้นฉบับ หากไม่มีเดือน วัน หรือ SKU ที่อ่านได้ จะไม่ส่งออก
- **ลำดับชิ้นงาน**: ค้นวัตถุ `TextFrame` (Type) ภายใน Layer `Name` รวม Group ซ้อนกัน อ่านจากชื่อวัตถุ เช่น `N3-BC` ได้ 3 และ `N12-BC` ได้ 12 ใช้จุดกึ่งกลาง `geometricBounds` ของวัตถุเพื่อตรวจว่าอยู่ในกรอบส่งออกใด โดยขอบร่วมเป็นของกรอบทางขวาหรือด้านล่าง
- **Order ID**: ค้นวัตถุ Type ภายใน Layer `OID` รวม Group ซ้อนกัน นับตามลำดับซ้อนใน Layers panel จากล่างขึ้นบน ไม่ใช้ตำแหน่งบนหน้ากระดาษ Type ล่างสุดเป็นออเดอร์ที่ 1 อ่านค่าจาก **Name ของวัตถุ** ก่อน หาก Name ว่างจะอ่าน `contents` ซึ่งเป็นข้อความที่ Illustrator แสดงแทนชื่อใน Layers panel รองรับเลขล้วนหรืออักษรอังกฤษผสมตัวเลข เช่น `123456`, `ABC123` และ `123ABC` โดยเก็บเป็นข้อความเพื่อรักษาศูนย์นำหน้าและเลขออเดอร์ยาว
- **การจับคู่**: `N3-BC` ใช้ OID ลำดับที่ 3 เสมอ เลขในชื่อไฟล์เป็น `003` แม้กรอบก่อนหน้าถูกข้าม ไม่ใช่ลำดับกรอบซ้ายไปขวา เลขตั้งแต่ 1000 ขึ้นไปไม่ถูกตัด
- **วันเวลา**: บันทึกใน log แทนชื่อ JPG ใช้เวลาท้องถิ่นของเครื่อง โดยอ่านเวลาที่ส่งออกแต่ละภาพเสร็จใหม่หลัง `exportFile` สำเร็จ

หากค่า OID ในช่องที่จับคู่ไว้ว่างหรือไม่ใช่เลขล้วน/อักษรอังกฤษผสมตัวเลข สคริปต์จะยังส่งออกภาพและใช้ `EmptyOID` แทน Order ID ในชื่อไฟล์ เช่น `N012-EmptyOID-002.jpg` ช่องนั้นยังนับเป็นลำดับเดิม จึงไม่เลื่อนออเดอร์อื่นมาแทน หากไม่มี Layer ที่ต้องใช้ ไม่มีเลขชิ้นงานในพื้นที่นั้น ไม่มีช่อง OID ตรงลำดับ กรอบเดียวพบเลขชิ้นงานหลายเลข หรือวัตถุระบุเลขอยู่ในหลายกรอบที่ซ้อนกัน จึงจะข้ามกรอบเพื่อไม่เดาคู่ หากข้ามทั้งหมดจะยังเก็บ log ที่ปลายทางโดยไม่แก้ Artboard หรือ visibility เมื่อจบคิวจะแสดงจำนวนภาพที่ส่งออกและข้ามพร้อมตำแหน่ง log

ใช้ชื่อ Layer `Name` และ `OID` ตรงตามตัวพิมพ์ โดยค้น sublayer ได้และใช้ Layer แรกที่พบ ควรเก็บรายการ OID ไว้ใน Group เดียวตามลำดับที่ต้องการ

## บันทึกการส่งออก

หลังคลิก **เริ่มส่งออก** แต่ละ Job ที่ผ่านการตรวจ Layer กรอบและชื่อเอกสารจะสร้างไฟล์ UTF-8 ชื่อ `AutoCapture_Log_yyyymmdd_HHMMSS.txt` ในโฟลเดอร์เดียวกับ JPG โดยเวลาในชื่อ log คือเวลาเริ่ม Job นั้น หากชื่อซ้ำภายในวินาทีเดียวจะเติม `_02`, `_03` เพื่อเก็บประวัติเดิม การเลือกปลายทางอย่างเดียวยังไม่สร้าง log

- `START`: ชื่อ/พาธต้นฉบับ, SKU, Set, ปลายทาง, DPI, คุณภาพ JPG และจำนวนกรอบ/รายการที่เตรียมส่งออก/รายการที่ข้าม โดยชื่อที่ลงท้ายด้วยเลขชุด เช่น `N012-11-01` จะแสดงเป็น `SKU=N012-11, Set=01` ส่วนชื่อที่ไม่มีเลขชุดจะไม่เพิ่มช่อง Set
- `EXPORTED`: วันเวลาที่ส่งออกภาพนั้นเสร็จ, ลำดับกรอบ, ลำดับชิ้นงาน, OID, ชื่อไฟล์และขอบเขตภาพ
- `SKIPPED`: ลำดับกรอบ/ชิ้นงาน, พิกัดและเหตุผลที่ข้าม เช่น ไม่มีเลขชิ้นงาน ไม่มี OID หรือข้อมูลกำกวม
- `ERROR` และ `END`: ข้อผิดพลาด รวมปัญหาการคืนสถานะ และผลรวมที่ส่งออกแล้ว ข้าม และยังไม่ได้ส่งออก

เขียนและปิด log หลังแต่ละรายการเพื่อเก็บผลก่อนหน้าไว้เมื่อภาพถัดไปส่งออกผิดพลาด หากสร้างหรือเขียน log ไม่สำเร็จจะหยุดและแจ้งข้อผิดพลาด การยกเลิกเลือกปลายทางไม่สร้าง log ชื่อ JPG ไม่มีเวลาแล้ว การส่งออกซ้ำไปโฟลเดอร์เดิมอาจเขียนทับ JPG ชื่อเดิมตามพฤติกรรม Illustrator

## พฤติกรรมที่ต้องทราบ

- ค้นหา Layer หรือ Group รวมระดับซ้อนที่ชื่อตรงกับ `frameLayerNames` และใช้ container แรกที่พบเพียงแห่งเดียว ไม่รวมกรอบจากหลาย container
- ใช้ `PathItem` ที่เป็นเส้นปิด 4 จุดและมีค่า `height > 1` เป็น Rectangle กรอบ โดยไล่ค้น Group และ sublayer ภายใน container ที่เลือก แต่ไม่ไล่ภายใน Compound Path
- ใช้เฉพาะกรอบที่พบจริงในเอกสาร ทุก SKU รวมถึง `N012` ต้องมีกรอบครบตามพื้นที่ที่ต้องการส่งออก ไม่มีการเติมพิกัดกรอบทางขวาอัตโนมัติ
- เรียงกรอบจากซ้ายไปขวาตามค่า left ของ `geometricBounds` หาก left เท่ากันจะคงลำดับจาก collection เดิม ไม่ได้เรียงเป็นแถวบนลงล่าง
- ซ่อน Layer หรือ Group กรอบที่เลือกทั้ง container ระหว่างส่งออก จึงไม่ควรเก็บงานภาพที่ต้องการส่งออกไว้ใน container เดียวกัน
- ซ่อน Layer ชื่อ `Border` ทุกตัว รวม sublayer ระหว่างส่งออก และคืน visibility เดิมของแต่ละ Layer หลังจบงานหรือเกิดข้อผิดพลาด หากไม่มี `Border` จะส่งออกตามปกติ
- ใช้ Artboard แรกเป็นพื้นที่ส่งออกชั่วคราว และเลือก Artboard นี้ให้ active ระหว่างส่งออก
- คืนขอบเขต Artboard, การแสดง Layer และ Artboard ที่ active เดิม ทั้งเมื่อสำเร็จและเมื่อส่งออกผิดพลาด หากคืนค่าใดไม่สำเร็จจะยังพยายามคืนค่าอื่นและแจ้งข้อผิดพลาด
- หากยกเลิกการเลือกโฟลเดอร์ จะไม่แก้สถานะเอกสารหรือส่งออกไฟล์
- เอกสารที่ยังไม่บันทึกใช้โฟลเดอร์ Documents เป็นจุดเริ่มต้นของหน้าต่างเลือกปลายทาง
- เลือกปลายทางใน UI ก่อนเริ่มคิว และตรวจข้อมูลการตั้งชื่อก่อนแก้ Artboard หรือ visibility
- หากส่งออกบางไฟล์แล้วเกิดข้อผิดพลาด ไฟล์ที่ส่งออกก่อนหน้ายังอยู่ ไฟล์ชื่อซ้ำอาจถูกเขียนทับตามพฤติกรรมของ Illustrator
- สคริปต์ไม่บันทึกต้นฉบับอัตโนมัติ EPS ที่สคริปต์เปิดจากคิวจะถูกปิดแบบไม่บันทึกหลัง Job ส่วนเอกสารที่เปิดอยู่ก่อนแล้วจะคงเปิดไว้ การเปลี่ยน Artboard ชั่วคราวอาจทำให้เอกสารที่คงเปิดอยู่แสดงว่าถูกแก้ไข แม้จะคืนขอบเขตเดิมแล้ว

## จุดตั้งค่าสำหรับนักพัฒนา

แก้ `CONFIG` ที่ต้นไฟล์ โดยไม่ต้องแก้ลูปส่งออก:

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `frameLayerNames` | `["CutLine", "กรอบ", "Layout", "FrameLine"]` | ชื่อ Layer หรือ Group ที่ยอมรับ รวมระดับซ้อน ตรงตัวและแยกตัวพิมพ์เล็ก/ใหญ่ |
| `targetDPI` | `96` | ความละเอียดภาพ คำนวณ scale เป็น `(DPI / 72) * 100` |
| `jpegQuality` | `100` | คุณภาพ JPG ช่วง 0–100 |
| `fileNumberDigits` | `3` | จำนวนหลักขั้นต่ำของลำดับชิ้นงาน เช่น `012` |
| `exportArtboardIndex` | `0` | Artboard ที่ใช้ส่งออก เริ่มนับจาก 0 และต้องมีอยู่ในเอกสาร |
| `uiWidth` | `800` | ความกว้างเริ่มต้นของพื้นที่คิวและรายละเอียดใน ScriptUI |
| `includeSubfolders` | `false` | ค่าเริ่มต้นของตัวเลือกรวมโฟลเดอร์ย่อย |

ค่าปัจจุบันใช้ **96 DPI** ตามการตั้งค่าในสคริปต์ หากต้องการ 300 ให้แก้ `targetDPI` เป็น `300` ควรใช้จำนวนบวกสำหรับ DPI และจำนวนหลัก และตรวจข้อจำกัดขนาดภาพ/scale กับ Illustrator รุ่นที่ใช้งาน

## โครงสร้างและแนวทางแก้ไข

คงสคริปต์เป็นไฟล์เดียวเพื่อให้ส่งต่อและรันผ่าน Illustrator ได้โดยไม่ต้องติดตั้ง package หรือ build ส่วน helper อยู่ภายใน closure เพื่อไม่เพิ่มชื่อใน global scope

`showCaptureDialog()` สร้าง ScriptUI ในไฟล์เดียวกับกฎส่งออก ใช้ `runBatch()` จัดคิวและ `executeJob()` ส่งออกทีละเอกสาร ส่วน progress ใช้ callback กับ `dialog.update()` โดยไม่มีไฟล์ progress ชั่วคราว

| ส่วน | หน้าที่ / เมื่อใดควรแก้ |
| --- | --- |
| `showCaptureDialog()` | หน้าต่าง ScriptUI, คิวไฟล์/โฟลเดอร์, ช่อง path และ progress |
| `executeJob()` | ตรวจเอกสาร เตรียมรายการส่งออก และ log ราย Job |
| `findFrameContainer()` | กฎการเลือก Layer หรือ Group ตาม `frameLayerNames` |
| `collectFrames()` / `copyBounds()` | เลือก Rectangle ที่ `height > 1` รวม Group ซ้อน ถ่ายสำเนาพิกัด และเรียงลำดับก่อนแก้เอกสาร |
| `getSku()` | แยก SKU พร้อมเลขชุดเดิมจากชื่อ job โดยช่วงเวลา Platform และเลขชุดเป็นตัวเลือก |
| `prepareExports()` / `collectTextFrames()` | อ่าน Type ใน `Name` และ `OID` จับคู่ตามตำแหน่งและเลขชิ้นงาน แล้วข้ามกรอบที่ข้อมูลไม่ครบหรือกำกวม |
| `getDefaultFolder()` | โฟลเดอร์เริ่มต้น รวมกรณีเอกสารยังไม่บันทึก |
| `createExportOptions()` | ตัวเลือก JPG และ scale |
| `createOutputFile()` | ชื่อไฟล์ SKU พร้อมเลขชุดเดิม, Order ID และลำดับชิ้นงาน |
| `createLog()` / `appendLog()` / `finishLog()` | บันทึกรายละเอียดและวันเวลาส่งออกแต่ละภาพ รายการที่ข้าม ข้อผิดพลาดและสรุปผล |
| `exportFrames()` | เก็บสถานะ ส่งออก และเรียกคืนสถานะใน `finally` |
| `restoreDocumentState()` | พยายามคืนทุกสถานะและรวบรวมข้อผิดพลาด |
| `runBatch()` / `openJobDocument()` | เปิด EPS ทีละไฟล์ ปิดไฟล์ที่สคริปต์เปิดหลัง Job รันคิว หยุดเมื่อผิดพลาด และคืนเอกสารที่ active ก่อนคิว |
| `collectInputPaths()` / `collectEpsFiles()` | อ่าน path และรวบรวม EPS ในโฟลเดอร์ |
| `createBatchLog()` | สร้าง log สรุปคิวโดยเก็บ log ชื่อซ้ำเดิมไว้ |

ข้อกำหนดในการพัฒนาต่อ:

- บันทึกไฟล์เป็น UTF-8 เพื่อรักษาชื่อ Layer และข้อความภาษาไทย
- ใช้ JavaScript แบบ ES3 สำหรับ ExtendScript: `var`, function ปกติ และลูปพื้นฐาน หลีกเลี่ยง `let`, `const`, arrow function, module import และ API จาก Node/browser
- เก็บ `#target illustrator` และคำสั่งเรียกทำงานท้ายไฟล์ไว้
- หากเพิ่มการเปลี่ยนสถานะเอกสาร ต้องเก็บค่าก่อนเปลี่ยนและเพิ่มการคืนค่าใน `restoreDocumentState()` พร้อมทดสอบกรณีผิดพลาด

ก่อนปล่อยใช้งาน ให้ตรวจด้วย Illustrator รุ่นที่ทีมใช้งานจริง:

1. ใช้ชื่อ job `1028(M)-TT-N012-03-01.eps` วาง Type ใน Group ของ `Name` ที่ตำแหน่งแต่ละกรอบ เช่น `N3-BC` และเรียง Type ใน Group ของ `OID` จากล่างขึ้นบน ตรวจว่าเลขชิ้นงานจับคู่กับออเดอร์ตรงกันแม้วางกรอบหรือเลขสลับกันทางซ้ายขวา
2. ตรวจว่าเส้นกรอบไม่ติดภาพ ขนาดภาพถูกต้อง และคุณภาพ/DPI ตรงค่าตั้ง
3. ลองทั้ง Layer และ Group ชื่อ `กรอบ` หรือ `Layout` รวม Group ซ้อนและกรณีมีหลายชื่อ ตรวจว่าใช้ container แรกเพียงแห่งเดียว และไม่ใช้เส้นเปิด/วัตถุสูงไม่เกิน 1 pt เป็นกรอบ
4. เปิดเอกสารหลาย Artboard โดย active Artboard อื่นก่อนรัน ตรวจภาพและการคืน Artboard ที่ active เดิม
5. ลองยกเลิกเลือกโฟลเดอร์ เอกสารยังไม่บันทึก Layer ที่ซ่อนอยู่ และปลายทางที่เขียนไม่ได้ ตรวจข้อความและสถานะที่คืนมา
6. ตรวจซ้ำกับ EPS จริงที่ใช้ในงาน โดยเฉพาะ Group, Compound Path, clipping และเอฟเฟ็กต์ที่อาจมีขอบเขตภาพเกิน `geometricBounds`
7. เปิด `N012` ที่มีกรอบจริงจำนวนที่ทราบ ตรวจว่าจำนวนกรอบใน log ตรงกับ Rectangle ที่ผ่านเงื่อนไข และไม่มีพื้นที่ทางขวาถูกเติมเพิ่ม ทดลองเพิ่มหรือลบ Rectangle เพื่อให้จำนวนเปลี่ยนตามกรอบจริงเท่านั้น
8. ทดลอง OID แบบเลขล้วนและอักษรผสมตัวเลข เช่น `123456` และ `ABC123` จากนั้นลบค่า OID ลำดับที่ 2 จากทั้ง Name และ contents ตรวจว่ายังส่งออกช่องนั้นด้วย `EmptyOID` โดยคู่อื่นไม่เลื่อน แล้วลบเลขชิ้นงานในกรอบหนึ่งเพื่อตรวจว่าเฉพาะกรอบที่ไม่มีเลขชิ้นงานถูกข้าม
9. เปิด ScriptUI แล้วลองทั้ง **ส่งออกเอกสารที่เปิดอยู่ปัจจุบัน** และ **ส่งออกไฟล์ EPS จากคิว** รวม Browse EPS หลายไฟล์, Browse Folder, วาง path ที่มีภาษาไทย/ช่องว่าง และเลือกปลายทาง ทั้งก่อนและหลังติ๊กรวมโฟลเดอร์ย่อย รวมการปิดหน้าต่างก่อนเริ่มว่าต้องไม่สร้าง log
10. รันคิว EPS อย่างน้อยสอง Job ตรวจว่าเปิดครั้งละหนึ่ง EPS และปิดแบบไม่บันทึกก่อนเปิดไฟล์ถัดไป ตรวจ progress ทั้งสองแถบ, Job/OID/ชื่อ JPG, log ราย Job และ log สรุปคิว ลองหยุดหลัง Job, export ผิดพลาด และไฟล์ที่เปิดไม่ได้ ตรวจว่าไฟล์ถัดไปเป็น `Not run` และเอกสารที่ผู้ใช้เปิดไว้ไม่ถูกปิด
