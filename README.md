# GC-AutoCapture

Change history / ประวัติการเปลี่ยนแปลง: [CHANGELOG.md](CHANGELOG.md)

สคริปต์ Adobe Illustrator สำหรับส่งออก JPG ตามขอบเขตกรอบใน Layer `กรอบ` หรือ `Layout` จากเอกสารที่เปิดอยู่ รองรับ EPS และเอกสาร Illustrator อื่น ๆ

## เริ่มใช้งาน

1. เปิดเอกสารใน Illustrator และเตรียม Layer ระดับบนสุดชื่อ `กรอบ` หรือ `Layout`
2. วาง PathItem ที่ต้องการใช้เป็นขอบเขตภาพไว้ใน Layer นี้โดยตรง
3. ตั้งชื่อเอกสารตาม job เช่น `1028(M)-TT-N012-03-01.eps` และเตรียม Layer `Name` กับ `OID` ตามรายละเอียดด้านล่าง
4. เลือก **File > Scripts > Other Script…** แล้วเปิด `GC-AutoCaputre.js`
5. เลือกโฟลเดอร์ปลายทาง จะได้ไฟล์ เช่น `N012-03_12345678901234567890_003_20261029154523.jpg`

ชื่อไฟล์ปัจจุบันสะกดว่า **GC-AutoCaputre.js** ตามไฟล์ในโปรเจกต์ โปรดใช้ชื่อนี้ในการติดตั้งและทดสอบ

## ชื่อไฟล์และการจับคู่ Order ID

รูปแบบส่งออกคือ `[SKU]_[Order ID]_ลำดับ_YYYYMMDDHHmmss.jpg`

- **SKU**: อ่านจากชื่อเอกสารรูปแบบ `วันที่(ช่วงเวลา)-Platform-SKU-ชุด` เช่น `1028(M)-TT-N012-03-01.eps` ได้ `N012-03` โดย `01` สุดท้ายเป็นลำดับชุดและไม่รวมใน SKU หากอ่านรูปแบบนี้ไม่ได้ จะไม่ส่งออก
- **ลำดับชิ้นงาน**: ค้นวัตถุ `TextFrame` (Type) ภายใน Layer `Name` รวม Group ซ้อนกัน อ่านจากชื่อวัตถุ เช่น `N3-BC` ได้ 3 และ `N12-BC` ได้ 12 ใช้จุดกึ่งกลาง `geometricBounds` ของวัตถุเพื่อตรวจว่าอยู่ในกรอบส่งออกใด โดยขอบร่วมเป็นของกรอบทางขวาหรือด้านล่าง
- **Order ID**: ค้นวัตถุ Type ภายใน Layer `OID` รวม Group ซ้อนกัน นับตามลำดับซ้อนใน Layers panel จากล่างขึ้นบน ไม่ใช้ตำแหน่งบนหน้ากระดาษ Type ล่างสุดเป็นออเดอร์ที่ 1 อ่านเลขจาก **Name ของวัตถุ** ก่อน หาก Name ว่างจะอ่าน `contents` ซึ่งเป็นข้อความที่ Illustrator แสดงแทนชื่อใน Layers panel และเก็บเป็นข้อความเพื่อรักษาศูนย์นำหน้าหรือเลขออเดอร์ยาว
- **การจับคู่**: `N3-BC` ใช้ OID ลำดับที่ 3 เสมอ เลขในชื่อไฟล์เป็น `003` แม้กรอบก่อนหน้าถูกข้าม ไม่ใช่ลำดับกรอบซ้ายไปขวา เลขตั้งแต่ 1000 ขึ้นไปไม่ถูกตัด
- **วันเวลา**: อ่านเวลาท้องถิ่นของเครื่องใหม่ก่อนส่งออกแต่ละภาพ เช่น 29/10/2026 15:45:23 ได้ `20261029154523` จึงไม่ใช้วันที่ในชื่อ job หรือเวลาเริ่มรันร่วมกันทั้งชุด

หากไม่มี Layer ที่ต้องใช้ ไม่มีเลขชิ้นงานในพื้นที่นั้น ไม่มี OID ตรงลำดับ หรือค่า OID ที่อ่านได้ว่าง/ไม่ใช่ตัวเลข จะข้ามกรอบนั้น ช่อง OID ที่ว่างยังนับเป็นลำดับเดิม จึงไม่เลื่อนออเดอร์อื่นมาแทน หากกรอบเดียวพบเลขชิ้นงานหลายเลข หรือวัตถุระบุเลขอยู่ในหลายกรอบที่ซ้อนกัน จะข้ามเพื่อไม่เดาคู่ หากข้ามทั้งหมดจะไม่เปิดหน้าต่างเลือกปลายทาง เมื่อส่งออกสำเร็จจะแจ้งจำนวนภาพที่ส่งออกและข้าม

ใช้ชื่อ Layer `Name` และ `OID` ตรงตามตัวพิมพ์ โดยค้น sublayer ได้และใช้ Layer แรกที่พบ ควรเก็บรายการ OID ไว้ใน Group เดียวตามลำดับที่ต้องการ

## พฤติกรรมที่ต้องทราบ

- ใช้ Layer แรกที่ชื่อตรงตามลำดับ Layer ในเอกสาร หากมีทั้งสองชื่อจะไม่รวมกรอบจากทั้งสอง Layer
- ใช้ทุก `PathItem` ใน `layer.pageItems` ไม่ได้ตรวจว่าเป็นสี่เหลี่ยมจริง และไม่ได้ไล่ค้นภายใน Group หรือ Compound Path เพิ่มเติม
- เรียงกรอบจากซ้ายไปขวาตามค่า left ของ `geometricBounds` หาก left เท่ากันจะคงลำดับจาก collection เดิม ไม่ได้เรียงเป็นแถวบนลงล่าง
- ซ่อน Layer กรอบทั้ง Layer ระหว่างส่งออก จึงไม่ควรเก็บงานภาพที่ต้องการส่งออกไว้ใน Layer เดียวกัน
- ซ่อน Layer ชื่อ `Border` ทุกตัว รวม sublayer ระหว่างส่งออก และคืน visibility เดิมของแต่ละ Layer หลังจบงานหรือเกิดข้อผิดพลาด หากไม่มี `Border` จะส่งออกตามปกติ
- ใช้ Artboard แรกเป็นพื้นที่ส่งออกชั่วคราว และเลือก Artboard นี้ให้ active ระหว่างส่งออก
- คืนขอบเขต Artboard, การแสดง Layer และ Artboard ที่ active เดิม ทั้งเมื่อสำเร็จและเมื่อส่งออกผิดพลาด หากคืนค่าใดไม่สำเร็จจะยังพยายามคืนค่าอื่นและแจ้งข้อผิดพลาด
- หากยกเลิกการเลือกโฟลเดอร์ จะไม่แก้สถานะเอกสารหรือส่งออกไฟล์
- เอกสารที่ยังไม่บันทึกใช้โฟลเดอร์ Documents เป็นจุดเริ่มต้นของหน้าต่างเลือกปลายทาง
- ตรวจข้อมูลการตั้งชื่อก่อนแก้สถานะเอกสารหรือเลือกปลายทาง กรอบที่เติมตาม SKU ต้องมีเลขชิ้นงานและ OID ที่จับคู่ได้เช่นเดียวกับกรอบจริง
- หากส่งออกบางไฟล์แล้วเกิดข้อผิดพลาด ไฟล์ที่ส่งออกก่อนหน้ายังอยู่ ไฟล์ชื่อซ้ำอาจถูกเขียนทับตามพฤติกรรมของ Illustrator
- สคริปต์ไม่บันทึกต้นฉบับอัตโนมัติ การเปลี่ยน Artboard ชั่วคราวอาจทำให้ Illustrator แสดงว่าเอกสารถูกแก้ไข แม้จะคืนขอบเขตเดิมแล้ว

## จุดตั้งค่าสำหรับนักพัฒนา

แก้ `CONFIG` ที่ต้นไฟล์ โดยไม่ต้องแก้ลูปส่งออก:

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `frameLayerNames` | `["กรอบ", "Layout"]` | ชื่อ Layer ที่ยอมรับ ตรงตัวและแยกตัวพิมพ์เล็ก/ใหญ่ |
| `targetDPI` | `72` | ความละเอียดภาพ คำนวณ scale เป็น `(DPI / 72) * 100` |
| `jpegQuality` | `100` | คุณภาพ JPG ช่วง 0–100 |
| `fileNumberDigits` | `3` | จำนวนหลักขั้นต่ำของลำดับชิ้นงาน เช่น `012` |
| `exportArtboardIndex` | `0` | Artboard ที่ใช้ส่งออก เริ่มนับจาก 0 และต้องมีอยู่ในเอกสาร |
| `skuFrameRules` | กฎสำหรับ `N012` | เพิ่มพิกัดส่งออกทางขวาสำหรับ SKU ที่กรอบท้ายขาด |

ค่า DPI เดิมที่ทำงานจริงคือ **72** แม้คอมเมนต์เดิมเขียนว่า 300 จึงคง 72 ไว้ หากต้องการ 300 ให้แก้ `targetDPI` เป็น `300` ควรใช้จำนวนบวกสำหรับ DPI และจำนวนหลัก และตรวจข้อจำกัดขนาดภาพ/scale กับ Illustrator รุ่นที่ใช้งาน

## SKU ที่ขาดกรอบสุดท้าย

ตั้งค่าที่ `CONFIG.skuFrameRules` ในไฟล์สคริปต์ ปัจจุบัน `N012` เพิ่มภาพทางขวา 1 ภาพ โดยใช้ขนาดเท่ากรอบสุดท้ายและไม่มีช่องว่าง เป็นค่าตั้งต้นที่ต้องตรวจเทียบกับ EPS จริงก่อนใช้งานผลิต

ชื่อ SKU จับจากชื่อเอกสารโดยไม่แยกตัวพิมพ์เล็ก/ใหญ่ และต้องเป็นคำเต็มที่คั่นด้วยอักขระอื่นนอกจาก A–Z, 0–9 เช่น `N012.eps`, `job_N012-v2.ai` ใช้ได้ แต่ `N0120.eps` และ `XN012.eps` ไม่ตรง หากมีหลาย SKU ที่ตั้งกฎไว้ในชื่อเดียวกัน จะแจ้งข้อผิดพลาด

ตัวอย่างเพิ่ม SKU ใหม่ (แทน `SKUใหม่` ด้วยรหัสจริง):

```javascript
skuFrameRules: {
    N012: {
        additionalFrames: 1,
        expectedFrameCount: null,
        width: null,
        height: null,
        gap: 0,
        topOffset: 0
    },
    SKUใหม่: {
        additionalFrames: 1,
        expectedFrameCount: 4,
        width: null,
        height: null,
        gap: 10,
        topOffset: 0
    }
}
```

| ค่า | ความหมาย |
| --- | --- |
| `additionalFrames` | จำนวนภาพที่เพิ่ม ต้องเป็นจำนวนเต็มตั้งแต่ 0 ใช้เมื่อ `expectedFrameCount` เป็น `null` |
| `expectedFrameCount` | จำนวนภาพทั้งหมดที่ควรมี แนะนำให้ใส่เมื่อทราบ เช่น `4` จะเติมเฉพาะส่วนที่ขาดจนถึง 4 หากมีครบหรือเกินแล้วจะไม่เพิ่ม |
| `width`, `height` | ขนาดภาพใหม่ เป็นจำนวนบวก หรือ `null` เพื่อใช้ขนาดของกรอบสุดท้ายที่ตรวจพบ |
| `gap` | ระยะจากขอบขวาของกรอบก่อนหน้าไปขอบซ้ายของกรอบใหม่: 0 = ต่อกัน, บวก = เว้นช่อง, ลบ = ซ้อนทับ |
| `topOffset` | เลื่อนขอบบนเทียบกับกรอบสุดท้ายที่มีจริง: บวก = ขึ้น, ลบ = ลง ไม่สะสมเมื่อเพิ่มหลายภาพ |

ขนาดและระยะทั้งหมดเป็น **points**: 72 pt = 1 นิ้ว, 1 มม. = 72 / 25.4 pt ตัวอย่างกรอบล่าสุด `[110, 100, 210, 40]` ด้วยค่าเริ่มต้นจะได้ภาพเพิ่มที่ `[210, 100, 310, 40]`

กรอบอ้างอิงคือกรอบตัวสุดท้ายหลังเรียงจากซ้ายไปขวา วิธีนี้เหมาะกับภาพท้ายที่ต่อทางขวาในแถวเดียวกัน ต้องมีกรอบจริงอย่างน้อยหนึ่งกรอบ และไม่ตรวจเนื้อหาภาพเพื่อเดาขนาดหรือจำนวนภาพ หากปล่อย `expectedFrameCount: null` จะเพิ่มตาม `additionalFrames` เสมอแม้ต้นฉบับมีกรอบครบแล้ว การเพิ่มนี้สร้างเฉพาะพิกัดส่งออก ไม่สร้าง PathItem ในเอกสาร

## โครงสร้างและแนวทางแก้ไข

คงสคริปต์เป็นไฟล์เดียวเพื่อให้ส่งต่อและรันผ่าน Illustrator ได้โดยไม่ต้องติดตั้ง package หรือ build ส่วน helper อยู่ภายใน closure เพื่อไม่เพิ่มชื่อใน global scope

| ส่วน | หน้าที่ / เมื่อใดควรแก้ |
| --- | --- |
| `run()` | ลำดับการทำงาน การตรวจเอกสาร และข้อความ UI |
| `findFrameLayer()` | กฎการเลือก Layer |
| `collectFrames()` / `copyBounds()` | เลือกกรอบ ถ่ายสำเนาพิกัด และเรียงลำดับก่อนแก้เอกสาร |
| `appendSkuFrames()` | เลือกกฎตาม SKU แล้วเติมพิกัดภาพท้ายจากขอบขวาของกรอบสุดท้าย |
| `getSku()` | แยก SKU จากชื่อ job โดยตัดวันที่ Platform และเลขชุด |
| `prepareExports()` / `collectTextFrames()` | อ่าน Type ใน `Name` และ `OID` จับคู่ตามตำแหน่งและเลขชิ้นงาน แล้วข้ามกรอบที่ข้อมูลไม่ครบหรือกำกวม |
| `getDefaultFolder()` | โฟลเดอร์เริ่มต้น รวมกรณีเอกสารยังไม่บันทึก |
| `createExportOptions()` | ตัวเลือก JPG และ scale |
| `createOutputFile()` | ชื่อไฟล์ SKU, Order ID, ลำดับชิ้นงาน และเวลาใหม่ของแต่ละภาพ |
| `exportFrames()` | เก็บสถานะ ส่งออก และเรียกคืนสถานะใน `finally` |
| `restoreDocumentState()` | พยายามคืนทุกสถานะและรวบรวมข้อผิดพลาด |

ข้อกำหนดในการพัฒนาต่อ:

- บันทึกไฟล์เป็น UTF-8 เพื่อรักษาชื่อ Layer และข้อความภาษาไทย
- ใช้ JavaScript แบบ ES3 สำหรับ ExtendScript: `var`, function ปกติ และลูปพื้นฐาน หลีกเลี่ยง `let`, `const`, arrow function, module import และ API จาก Node/browser
- เก็บ `#target illustrator` และคำสั่งเรียกทำงานท้ายไฟล์ไว้
- หากเพิ่มการเปลี่ยนสถานะเอกสาร ต้องเก็บค่าก่อนเปลี่ยนและเพิ่มการคืนค่าใน `restoreDocumentState()` พร้อมทดสอบกรณีผิดพลาด

## ตรวจสอบก่อนส่งต่อ

รันชุดทดสอบจำลอง Illustrator API ด้วย Windows PowerShell และ Windows Script Host (JScript) โดยไม่ต้องติดตั้ง Node.js หรือเปิด Illustrator:

```powershell
powershell.exe -NoProfile -File .\tests\run-tests.ps1
```

ชุดทดสอบอ่านไฟล์ `.js` จริง ตัดเฉพาะ `#target` และรันผ่าน `cscript.exe` เพื่อตรวจการเติมกรอบ SKU การปรับขนาดและระยะ การป้องกันภาพซ้ำด้วยจำนวนภาพเป้าหมาย การจับคู่เลขชิ้นงานกับ OID จากล่างขึ้นบน การข้ามข้อมูลไม่ครบโดยไม่เลื่อนคู่ การอ่าน Name ของชิ้นงานและการอ่าน contents ของ OID เมื่อ Name ว่าง การรักษาเลขออเดอร์ยาว/ศูนย์นำหน้า เวลาแยกรายภาพเมื่อข้ามปี และการคืนสถานะ รวมกรณียกเลิกหรือส่งออกผิดพลาด ไม่ได้สร้าง JPG จริงหรือยืนยันผล render ของ Illustrator

ทดสอบส่งออกจริงเมื่อ 29/10/2026 ด้วย Illustrator 28.6.0 กับ `1028(M)-TT-N012-16-01.eps` ที่เปิดอยู่: ส่งออก 4 JPG ตาม OID ลำดับ 1–4 และข้าม 4 ตำแหน่งที่ไม่มีข้อมูล ตรวจภาพทั้ง 4 แล้ว พร้อมตรวจการคืน Artboard/visibility และ SHA256 ของ EPS บนดิสก์ว่าไม่เปลี่ยนแปลง การทดสอบนี้ใช้สถานะเอกสารที่เปิดอยู่โดยไม่บันทึก EPS

ก่อนปล่อยใช้งาน ให้ตรวจด้วย Illustrator รุ่นที่ทีมใช้งานจริง:

1. ใช้ชื่อ job `1028(M)-TT-N012-03-01.eps` วาง Type ใน Group ของ `Name` ที่ตำแหน่งแต่ละกรอบ เช่น `N3-BC` และเรียง Type ใน Group ของ `OID` จากล่างขึ้นบน ตรวจว่าเลขชิ้นงานจับคู่กับออเดอร์ตรงกันแม้วางกรอบหรือเลขสลับกันทางซ้ายขวา
2. ตรวจว่าเส้นกรอบไม่ติดภาพ ขนาดภาพถูกต้อง และคุณภาพ/DPI ตรงค่าตั้ง
3. ลองทั้งชื่อ Layer `กรอบ` และ `Layout` รวมกรณีมีทั้งสองชื่อ
4. เปิดเอกสารหลาย Artboard โดย active Artboard อื่นก่อนรัน ตรวจภาพและการคืน Artboard ที่ active เดิม
5. ลองยกเลิกเลือกโฟลเดอร์ เอกสารยังไม่บันทึก Layer ที่ซ่อนอยู่ และปลายทางที่เขียนไม่ได้ ตรวจข้อความและสถานะที่คืนมา
6. ตรวจซ้ำกับ EPS จริงที่ใช้ในงาน โดยเฉพาะ Group, Compound Path, clipping และเอฟเฟ็กต์ที่อาจมีขอบเขตภาพเกิน `geometricBounds`
7. เปิด `N012` ตรวจภาพท้ายที่เพิ่มว่าตำแหน่งและขนาดตรงกับงาน ปรับ `width`, `height`, `gap`, `topOffset` และตั้ง `expectedFrameCount` เมื่อทราบจำนวนภาพที่ควรมี
8. ลบ Name ของ OID ลำดับที่ 2 หรือลบเลขชิ้นงานในกรอบหนึ่ง ตรวจว่าข้ามเฉพาะกรอบที่ข้อมูลขาดและคู่อื่นไม่เลื่อน ตรวจเวลาในชื่อไฟล์เทียบกับเวลาส่งออกจริง
